# 新手引导 HTML 审核稿

入口：index.html。文档：../../docs/reviews/2026-10-11-onboarding-ui-design.md。

这是新增桌面引导的交互设计媒介，不是安装版代码。背景只示意弹窗位置，不能替换真实 DashboardShell 等组件。资料、头像与模型为设计占位，只保存在当前页面内存；请勿输入真实 Key。没有供应商网络请求或应用 IPC。

上方审核工具切换完整/仅模型流程、步骤、主题、尺寸、失败状态与既有模型选择。iframe 内为每步独立 dialog；正文在短窗内滚动。按 Escape 暂时退出，入口可演示从未确认步骤继续；刷新重置全部预览状态。

`node design/onboarding/capture-preview.mjs` 检查设计查看器并生成本目录截图与 preview-checks.json。需本机 Google Chrome 和仓库 @playwright/test。该命令不运行产品测试，不验证 Electron、磁盘持久化或真实供应商权限。

v3 已获用户 UI 批准（2026-10-11），包括移除移动光带的最终修订。保留此前移除步骤条和冗余说明、放大主题区的修订；主题、资料、文本及文生图模型主按钮统一为“继续”，最后一页重设计为“欢迎使用”，展示品牌印记、笔名问候与“开始创作”。首版源文件和预览证据保留于 archive-v1/。通过后再开始产品实现与本次相关测试。

“继续”先校验与保存再推进；文本同时设为默认文本与审核，图片设为默认文生图。欢迎页移除配置摘要清单；“开始创作”、关闭或 Escape 都进入工作台。供应商仍按国产优先、国外随后、自定义最后排列，DeepSeek 为文本首项。

已同步预览驱动与文档；现有截图/preview-checks.json 是此前 v2 运行的历史预览结果，未覆盖资料按钮、提示框、排序及 v3 欢迎页修订。本轮只核对源码、脚本语法和文档一致性，未重新生成截图。

最新展示素材：文生图询问卡片使用 assets/xianxia-character-scene-v2.png “角色＋场景”仙侠拼贴横幅，比例 2:1、尺寸 1774 × 887px。询问对话框宽 640px，图片铺满卡片，介绍置于下方，窄窗等比缩小。生成提示词与来源见 assets/xianxia-character-scene-v2.md，原肖像保留为历史素材。该图为随设计稿附带的本地静态展示素材，不使用用户头像或模型配置；已检查生成图片及源码引用，未重新渲染卡片，旧预览证据不覆盖此修改。

图片现为可点击按钮，与下方“配置文生图模型”进入同一页面。悬停为手形，画面轻微推进，楷体配置文字渐入；键盘聚焦呈现同样提示，Enter/Space 可激活。触控直接点击，减少动态效果时只显文字和衬底；提交期间图片同步禁用。按最新要求移除移动光带及其样式和状态变量。此轮只做语法与源码核对，没有把历史截图算成此次动画或点击的运行证据。
