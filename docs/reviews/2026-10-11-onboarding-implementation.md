# 新手引导实现记录

2026-10-11，依据用户批准的 UI v3及后续文案、图片交互修改，实现范围限于本次新手引导。

首次进入本地数据目录，缺少完成记录时启动完整流程：选择主题 → 用户信息 → 文本模型 → 文生图询问 → 可选图片模型 → 欢迎使用。未完成的完整流程从已确认步骤恢复；完成后没有任何TEXT记录时每个renderer会话提示一次，模型空态和缺文本模型的配置动作进入短流程。停用TEXT记录仍按存在处理，保留原精确错误入口。

`OnboardingController` 使用独立主题/图片询问/欢迎Dialog；资料编辑器从原ProfileSettings同文件抽取复用，模型编辑器沿用ModelConfigurationDialog单选。引导确认按钮为“继续”，普通设置仍“保存/保存模型”。真实DashboardShell、SidebarTree、ChatPanel、内容面板与MarkdownEditor均继续使用已有组件，没有复制原型工作台。

`ModelRepository.commitOnboarding`一次CAS保存模型、默认用途及进度。TEXT设置默认文本和审核模型，IMAGE设置默认文生图模型；跳过保留原图片配置。主题即时持久化，资料手动确认；新建稳定ID、已确认步骤回退编辑同ID。确认不测试连接、不生成图片、不创建作品或自动重发任务。

新增严格IPC、owner/session和关闭/迁移/lease准入复核；提交经过既有写队列与关闭flush屏障。Key只交给已有系统加密通道，公开状态及进度不含秘密或派生摘要。写后同步错误用原固定envelope重新确认权威状态，不重复模型、加密或授权版本；编辑器专用retry绕过已提交后的本地重复模型及失效头像会话校验。

高优先级弹窗暂停引导但保留内存字段及已接受头像。头像选择使用UI已接受draftId和候选草稿分离，取消选择可恢复前者；已打开或尚在队列的迟到选择均失效。连接测试可返回/跳过/退出取消，迟到finally不能释放后续保存锁。模型保存期间阻止这些操作。实际短窗口发现的退出焦点问题已修复：返回可见原入口，或可见账号菜单、紧凑导航、消息输入框。

仙侠拼贴图片作为本地资源打包，图片按钮与页脚动作相同；pointer、缩放/衬底/楷体提示及减少动态效果均保留，没有移动光带。国产供应商在前，DeepSeek为TEXT首项；IMAGE仅列已有支持子集。

技术及测试审核见同目录 technical-review/test-review；TDD证据在 `docs/evidence/onboarding/`。最终独立code review与验证结果由各自记录说明，不将HTML历史截图或受控组件测试当作真实目标系统证据。
