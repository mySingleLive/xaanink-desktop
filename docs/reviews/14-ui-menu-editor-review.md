## 源码与设计核对

- **菜单与命令来源。** macOS 六组菜单位于工具行下方的系统桌面位置示意，不加入三栏头部；Windows 菜单入口在右上窗控左侧，五组菜单与二级项共用 `desktop-commands.js` 的稳定 ID、标签和当前平台绑定。Windows 文件中的设置、关闭窗口、退出为独立命令，帮助含关于；未上线文档禁用。菜单逐层 Escape/方向导航、外部关闭、窄窗定位、模态期间禁用入口及平台切换关闭旧菜单均有源码路径。最终原生菜单及菜单打开前编辑焦点路由另列阶段边界。
- **模型目录与草稿。** 预设供应商保留 Key 和可用模型搜索下拉；新增为复选，编辑已有记录为单选，行选中状态同步，重复记录禁选。收起显示数量/名称，菜单限制高度、可滚动且空间不足向上展开。80 条滚动压力场景使用明确 demo ID，不冒充真实供应商目录。搜索与选择只改配置草稿；供应商切换清该草稿 Key/选择，取消不保存。直接测试先关闭菜单，锁入口/搜索/选项/保存；候选快照和会话/批次检查隔离迟到结果，完成后结果层返回原配置 DOM，测试不提交保存。失败保留草稿与已保存记录。
- **图标与自定义参数。** OpenAI/GPT 家族为本地黑白标，玄墨反转白色；Kimi 为官方 K 字形和用户指定黑色圆角底板，月之暗面供应商图标独立。目录、已保存两组模型、智能体与当前对话共用家族映射。自定义去掉输出上限输入；上下文支持空值、正整数、K/M 十进制单位，保存规范化为正整数 token，非法值不提交。隐藏协议默认参数仍是后续真实请求职责，字段删除不证明真实接口兼容。
- **外观与编辑草稿。** 界面和正文分别配置字体/字号/缩放及字体/字号/行距/行号/换行；阅读预览无行号，源码默认不换行。即时外观只更新 CSS、textarea 属性及 gutter，不重建 textarea，保留输入值与选区；失败继续应用已确认配置并保留待处理值。软换行 gutter 按每逻辑行的实际字体和内容宽度测高，滚动同步，ResizeObserver 随面板尺寸重算。完整 Monaco 撤销、评论锚点与字体解析不属于当前 textarea 演示的已完成能力。
- **快捷键。** 四类过滤/搜索显示命令 ID、作用域、默认/当前绑定、未绑定项和锁定项，共享编辑动作只保留一份 ID。macOS/Windows 自定义映射分开；录制与恢复确认在平台切换时取消，其他模型草稿保留。相同作用域及全局/共享文本动作检查相等或前缀冲突，互斥的输入域可复用；每段 chord 拒绝保留键，重复 modifier/别名拒绝。失败不更新绑定，取消不提交，恢复仅覆盖当前平台。键盘层均忽略已消费事件与 IME composing/229。

## 发现与修复

| 编号 | 初始问题 | 源码复审结果 |
| --- | --- | --- |
| UI9-01 | Windows 文件菜单缺退出，关闭窗口不能代替应用退出。 | `app.quit` 覆盖两平台，Windows 无默认键，文件中保留独立 `window.close`；已修复。 |
| UI9-02 | 在录制/恢复确认期间切平台，确认会写入新平台映射。 | 切换前只取消快捷键录制/恢复弹框，清录制状态；模型配置层保持；已修复。 |
| UI9-03 | 保留组合藏在 chord 后段可绕过校验，前缀与重复 modifier 未拒绝。 | 逐 chord 对比系统/锁定默认键，比较规范化相等/前缀，重复别名归一后拒绝；已修复。 |
| UI9-04 | Windows 子菜单返回根后父项 `aria-expanded` 仍为 true。 | 返回时隐藏二级、清父项展开状态并聚焦父项；已修复。 |
| UI9-05 | 软换行按固定一行计 gutter，后续逻辑行号错位。 | 内容宽度/字体镜像逐逻辑行测高，ResizeObserver/滚动重算；A08–A10 和独立看图复核通过，已关闭。 |
| UI9-06 | 上层忽略中文组词 Escape 后，通用键盘层仍可能关闭配置并丢草稿。 | 所有层使用 defaultPrevented/isComposing/keyCode 229 守卫；已修复，真实两平台 IME 留最终验收。 |
| UI9-07 | 主代理 GUI 发现 Windows 无内容模式的旧高优先级安全区覆盖新值，内容按钮看似可见但被窗控挡住点击。 | 各模式旧值统一 196px，窄窗普通/无内容/全内容显式 172px；源码及 O18–O20 命中/点击复核通过，已关闭。 |

UI9-05 的最终 A08–A10 与独立看图已闭环：640 窄窗首个逻辑行占三物理行，第二/三逻辑行号仍对齐；字号由 20px 增至 22px 后重算，1280 面板扩大后首行降至两物理行，草稿保留。UI9-07 的 O18/O20 只读 DOM 命中检查与 O19 实际内容切换/输入已通过，不能仅凭可见图标认定可点击。

补查：编辑单选会同步所有行的 `aria-selected`；macOS 左/右方向可切相邻菜单组。本轮修复前状态不计为通过证据。

## 阶段边界

本审核仅为设计与浏览器内存原型，主代理执行 GUI，本子代理独立审源码/截图/记录；不是 Electron 或真实 Windows 验收。没有真实供应商全量目录/Key 网络请求、费用、剪贴板、系统热键、原生退出、原子磁盘保存、安装包、完整 Monaco/评论撤销或真实 IME 实测。字体当前为本地回退链示意，正式 App 仍须报告实际可用/回退字体并验证编辑状态保护。

用户仍须明确批准 UI；批准后按原顺序进入技术方案、最终测试用例、TDD App 实现和真实双平台验收。本轮产品审核或修改指示不构成 UI 批准。
