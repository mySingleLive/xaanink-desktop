## 源码核对

- 主题进入「界面」首行，保留上下全宽三图、短设置左右及语义配色；设置外缘两主题投影与调试工具独占行保持。首次中央仅创建作品入口，离线创作仍可进行。
- 录制框只读，keydown 捕获在 modal handlers 前消费事件；一个完整 chord 停录并聚焦保存，单独修饰键只显示预览、释放恢复上个完整草稿。Tab/Escape 可作为组合本身录制；键名 helper 处理物理字母、数字、符号及数字键盘，忽略 composition/repeat/Dead/Unidentified。显式按钮和输入框点击可重录，追加按钮只追加一段；停录后键盘焦点不得自动开始新录制。
- 所有当前平台绑定按作用域参与相等/前缀/别名冲突；同命令与系统保留仍内联拒绝。跨命令层列出每个匹配绑定并保留录制草稿，父录制层 inert，最高层 Tab/Escape 独立。取消返回保存入口；查看按稳定 ID 展开全部分类并可见定位，不保存当前草稿。
- 转移保存重新计算冲突；冲突集合变化先重新展示确认。失败在新集合赋值前返回，原集合不变；成功构建独立 next 对象，仅移除每个匹配索引，再一次替换当前平台映射。其余绑定、默认首项、显式空与另一平台保持；完成后菜单主绑定同步。
- 外点关闭按设置与子窗的联合范围判定，仅消费实际外部鼠标点击，跳过调试工具和键盘生成点击，不穿透工作台。关闭失效测试批次/模型会话、取消头像读取/会话、丢弃模型/资料/录制/目录选择上下文；不回滚已确认设置，不清创作输入。迁移阶段另有提交前/后关闭守卫。
- AI 共用门控按文本/审核/图像所需类别，检查对应选中索引、有效记录、启用与 Key；准确区分空配置、已有但不可用和未选择。引导聚焦对应添加入口，保留草稿/作品目录；配置后不自动执行。三类调试示意与发送入口不联网，不代表最终全部真实调用链已经覆盖。
- 迁移先打开平台目录选择示意，确认前显示当前根/大小、作品不移动和旧根清理范围。空/同根/不可写示意在选择框拒绝；取消不改根或开始进度，选择成功才复制/校验/提交/清理。运行中平台切换被拦截，回执仍归属原平台。默认父目录选择也按平台取消/确认，保留完整路径。
- Mac 应用菜单与 Windows 帮助菜单分别打开独立 About 示意，未导航设置；设置关于页保留。版本取安装元数据，未发布不冒称安装版本。Mac 系统字体/关闭交通灯、Windows 标题/确认及关闭返回关系由原型表现，真实原生行为留后续验收。

## 子代理定向验证

执行 `node --test design/check-shortcut-keys.cjs`，最终 7 个键名/规范化测试通过。另从当前源码提取实际 commands/commandKeys/scopeOverlap/shortcutHits/shortcutError/saveShortcut，在独立 Node VM 中运行 8 个场景，均通过：全部两项前缀冲突列明且不修改、转移失败保持全部集合、成功只删匹配索引并保留兄弟/默认/另一平台、冲突集合变化重新确认、三命令转移一次处理、切平台拒绝半次保存、同命令内联拒绝、第二 chord 系统保留拒绝。测试只使用隔离对象及显示函数替身，没有注入浏览器状态，也没有注册/执行系统热键。

另从最终源码提取录制 capture handler 与 armRecorder，在独立 VM 中验证 5 个事件场景，均通过：首个 Escape 捕获并返保存焦点、焦点变更后的 repeat 在 modal 前消费、停录 Tab 不重启、停录 IME Enter 不重启、全新 Enter 显式重录。这是脱离浏览器的源码处理函数验证，没有通过 UI 工具实际长按或注入浏览器事件，不计入 61 项 GUI 数量。

最终修改的 `desktop-preview.js` 与 `desktop-shortcut-keys.js` 执行 `node --check`，`git diff --check` 通过。

## 阶段边界

本轮只审核内存 UI 原型与 helper。真实系统按键拦截、IME/非美式布局、Electron 原生 About/目录选择、写权限/容量/身份/迁移事务、磁盘持久化和全部 AI 调用链尚未验收。GUI 由主代理执行，子代理独立审源码/截图/记录；用户仍须明确批准 UI，之后按原顺序进入技术方案、最终用例、TDD App 实现与真实双平台验收。
