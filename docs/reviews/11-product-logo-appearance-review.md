## 保存、分类与审核门

带 Logo 的智能体选择仍即时更新，只引用已保存、已启用、授权及输出类别匹配的模型；失败保留待处理引用并按原规则重试。用户资料与模型配置仍为独立保存例外，取消/X/Escape 不提交草稿；测试不保存、不改变智能体默认，迟到回调按会话/批次隔离。对话模型选择只影响当前会话，保留输入和编辑实例，不改智能体默认或自动发送请求。

原型目录、思考档位、模型与测试结果仍为示例；真实目录发现、授权、磁盘持久化、React 组件迁移和真实 Electron 两平台验收未因此完成。当前仅 UI 阶段，用户尚未批准；此次产品复审不能越过 UI 用户审核门，不提前进入技术方案、最终测试用例或 App 实现。

## 定向复核与最终结论

2026-10-07 重新读取产品 R08、第 7 节分类顺序、末尾设计审核条款及能力矩阵修订说明：两处实际分类名均已改为“外观”，PRD-LA01 关闭；外观/主题示意图已映射 D04，调试工具明确不新增安装版能力 ID，原 D05/D06 定义保留，PRD-LA02 关闭。产品还明确首次启动调试场景重置演示记录这一例外，与其他页面保留已保存记录的范围分开，未将演示重置施加到正式 App。

**最终结论：产品 v0.7 本轮修订通过，无待修复产品项。** UI v0.8 仍须完成独立 UI 审核并取得用户明确批准；没有据此开始或确认技术方案、App 实现、真实目录/模型调用或最终验收。
