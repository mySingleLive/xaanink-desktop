# UI v0.7 供应商与直接测试独立审核

日期：2026-10-07（Asia/Shanghai）。审核者：独立 UI 子代理。前序产品 v0.6 已通过 `09-product-provider-test-review.md`。范围：智谱名称/Logo、按输出能力筛选供应商、直接测试忙态/批次结果，以及相关模型/智能体与 Web UI 回归。

## 结论

**UI v0.7 独立审核通过，无遗留阻断项，可提交用户审核。** 最新三项修订在设计、源码和本版证据中一致，UI7-01、UI7-02 已关闭。浏览器由主代理独占，GUI 检查由主代理执行；本子代理独立审核源码、设计定义、14 张本地截图、检查记录及文件指纹，没有操作或重放 GUI。旧 v0.6 的 100 项不计为本版通过。

## 源码审核

- **名称与资源。** 运行预设、产品与 UI 使用「智谱」；Logo 已从旧图形改为 Z.ai 斜向 Z 图形。12 个本地 Logo 的 SHA-256 均与来源清单一致，SVG 静态结构不含脚本/外部资源引用，MIT 许可保留；着色与来源有明确记录。
- **分类供应商。** 菜单按相应输出类别的目录元数据筛选。示例文本为 12 家预设加自定义，文生图为 OpenAI、Google、xAI、智谱、阿里巴巴、MiniMax、腾讯、字节跳动加自定义；与本版文档一致，图片输入没有当作图像输出。自定义始终保留；既有保存记录不因菜单筛选而删除。目录及档位明确为示例，安装版动态发现和真实接口尚未完成。
- **直接测试与锁定。** 测试点击后直接启动整批已选目标，无前置确认层。配置内先显示数量、文本/图像请求和费用说明；按钮使用旋转图标、测试中 i/n 与 aria-busy，整批禁用。字段、供应商、型号、高级区及保存锁定；入口和输入处理另有忙态保护，取消/X/Escape 保持可用。解锁恢复原先已禁用的重复目录项，而非统一启用。
- **批次与取消。** 开始时复制候选目标，批次标识与编辑会话标识分别捕获；每项回调核验两者和当前草稿。关闭配置清计时器、递增两类标识并丢弃草稿，旧回调不能改新会话或弹出旧结果。测试不调用保存，也不改已确认列表/会话选择/智能体默认。
- **结果与原草稿。** 完成后附加覆盖层，原配置保持在 DOM 中并 inert，没有重新绘制 Key 输入。逐目标结果显示名称、ID、供应商、端点和状态，不显示 Key。返回/X/Escape 只移除结果层，恢复原配置并返焦测试按钮；原草稿仍须显式保存。主设置和原配置的 aria-modal/inert 随最高层切换，Tab/Shift+Tab 循环只取结果层可见可用控件。
- **回归与尺寸。** 两组已保存模型仍无选中高亮，模型手动保存/取消与智能体即时更新保持，先前停用/启用和引用隔离修复未回退。Web 创作组件来源绑定、底部用户菜单和资料独立保存保留。结果层有独立滚动体及窄窗内边距；本版 640px/1024px 截图与布局记录对应，忙态取消、结果返回及逐项内容可达，无已发现的横向溢出。

## 交互发现与证据边界

UI7-01（已关闭）：主代理 GUI 检查发现测试按钮禁用后 AX 焦点落到 WebArea；已在启动后显式聚焦配置的可用取消按钮，定向源码复核通过。最终 T26/T27 分别确认忙态焦点留在取消按钮、Tab 循环到配置关闭按钮。运行焦点结论来自这些 GUI 记录与源码共同核对。

UI7-02（已关闭）：子代理独立看图发现 `test-loading-ink-1024.jpg` 初次保存的是非忙态配置画面，与文件名不一致。主代理按实际忙态重拍，本子代理已独立确认最新画面与最终指纹。此项是证据修正，不据旧帧断言运行测试失败；旧帧不计为忙态证据。

浏览器对密码值脱敏；GUI 只能确认已填写状态。结果附加/移除不重绘原配置、也不改 Key 输入值的源码保证，与 GUI 明文相等实测分别记录。只读 DOM 接口不返回的 inert 属性以实际属性存在核对，不虚报属性读取结果。Logo 浏览器缓存修正后以最终资源与重拍图为准。
