# 三栏顶部窗口拖动方案

2026-10-09，来源：本轮用户红框与约束。仅修改真实 React 工作台的桌面标题命中区域。

1. AI：在 `ChatPanel.tsx` 现有 h-11 标题栏添加 `desktop-drag`，保持标题和恢复按钮的位置。将已有 StoryWorkflowBar 与恢复/创建状态提示放在标题栏之后，保证该标题栏始终处于 AI 区域实际顶部；这些状态行仍完整保留且不可拖。消息区、输入框和业务内容不增加拖动区域。
2. 右侧无 Tab：在 `ContentTabs.tsx` 增加 h-11、shrink-0 的空白顶部拖动条，和左侧/AI 标题栏高度一致。仍保留真实原空态。
3. 右侧有 Tab：给现有 Tab 导轨添加 `desktop-drag`，空白、边距可以拖动；现有 Tab 显式 no-drag。选中、键盘、关闭、中键关闭与两枚面板按钮维持原行为。
4. CSS 沿用 Electron `app-region: drag`，补充 `[role="tab"]` 排除与拖动区禁选文字。双击先验证原生标题栏最大化/复原；不加 DOM dblclick 与 IPC，避免原生拖动区屏蔽鼠标事件或重复切换。双击为真实目标系统的通过门，若未切换则修订原生方案，不能以 CSS 检查代替。

测试先于实现：用真实 React/CSS 组件浏览器测试验证三个命中区、交互后代、顶部以外无扩展、Tab 行为和溢出。再构建离线 Electron，在隔离数据根运行真实 macOS 窗口，验证鼠标拖动导致 bounds 移动及双击最大化/复原。完整单元/集成与浏览器回归、类型检查及构建记录本次结果；未实际运行的 Windows 验收据实保留。

仅更新 W04 的本次实现/证据，并给 ContentTabs 迁移条目添加有限范围开发记录，不把完整业务或跨平台验收标为完成。独立方案、用例及代码审核按 AGENTS.md 依次执行。
