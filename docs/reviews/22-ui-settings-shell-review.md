## 源码核对

- 设置主面板移除顶部 header 与介绍，左导航先渲染独立「设置」h2，再渲染七项分类及底部说明；右侧没有重复分类大标题。分组 h3、自动更新状态、手动保存提示、失败说明及重试入口保留。其他子对话框的标题与提交边界不改。
- 主面板使用全高两列 grid，窄窗仍为左右结构；左侧自行滚动，右侧 settings-body 自行滚动。关闭按钮处于右内容容器、带「关闭设置」名称和 title，与设置内容滚动分离。固定反馈和关闭区域由 settings-content 自身54px（窄窗50px）上内边距预留，滚动视口实际从其下开始；菜单定位仍以实际 settings-body 矩形为界。
- syncModal 仅在当前层不包含焦点时选入口；设置层优先关闭按钮，子层仍选择自身可用控件。workspace inert、子层打开后父设置 inert、最高层 Tab 与 Escape/外点关闭逻辑保持。
- 移除 settings-title 后，input 失败提示插入 settings-body 起始位置，不再访问已移除节点。renderSettings 保留 failureNotice，待处理修改、已确认设置及重试路径未变；不回滚已确认配置或创作输入。
- 跟随系统图示不再生成 system-emblem，其圆形/图标相关样式移除；纸/墨组合占位、图示外主题名称、aria-pressed 与三选一行为保持。没有新增资源或改变实际主题令牌。
