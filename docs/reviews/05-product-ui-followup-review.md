## 保留的验收边界

用户资料仅本地保存，不发送邮件；模型配置修改不自动联网，测试连接仍需作者主动操作；Key、目录授权、迁移权威根、失败恢复和候选稿保护没有因本次修改而放宽。尚未开始 App 技术与实现阶段，真实磁盘原子提交、两类模型路由、原生窗口及两平台验收仍属于后续任务。本审核不能将这些事项标记通过。

## 定向复核

2026-10-07 重新读取能力矩阵 D03 / D04：D03 已直接列出文本/文生图分组以及两类选择、用途路由隔离；D04 已直接限定自动更新不包含用户资料，并明确独立草稿、保存提交、取消/X/Escape 丢弃及失败保留/重试。与产品第 6、7 节和末尾资料提交约束一致，PRD-F01 关闭；迟到读取隔离仍由产品正文与 UI 第 8 节明确约束。最终结论维持通过，无待修复产品项；UI 仍待独立审核与用户批准。
