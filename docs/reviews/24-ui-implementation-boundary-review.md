## 已核对的实施边界

- 正式工作台来自原 Web 真实 React 组件：DashboardShell 两/三栏、SidebarTree 全部树/账户菜单、ChatPanel 与 chat 原子组件/AI composer、ContentTabs/registry、MarkdownEditor/Monaco。只允许窗控/菜单/目录/本地模型与数据传输等已授权差异，不复制设计原型的模拟工作台或重建同名简化业务面板。
- 原 registry 为29个 Tab 类型；章节大纲/作品大纲同用 OutlineProjectionPanel，多个规划类型共用 PlanningWorkspace，不能把组件文件数误当 Tab 能力数。作品、主题、世界、设定/属性、人物/物品/场景及图像、爽泪点、规划/大纲、正文/候选、连锁修订、子任务、试验场、伏笔、流程/评审/活动须保留实际组件与业务操作。
- 明确静态导出不带在线认证/管理台；安装包禁止 design/desktop-preview.*、演示作品/作者/精选示例型号/假Key/模拟成功/调试条，独立源码、资源与基线指纹不依赖父目录。主题图的无文字占位属于批准的产品图示，不能一并删除。
- 窗控/导航是原组件插槽，macOS 左侧系统按钮/后退/前进/侧栏开关、Windows 右控及菜单安全区、拖动/no-drag、全高分栏、显隐时原编辑实例均有技术约束。Mac 六菜单与 Windows 五菜单共用命令源，About 独立、版本读安装包、反馈主动外跳、未上线文档禁用。
- 设置采用七分类、v0.13纯左右/19与17px标题/固定关闭与反馈安全区；路径/主题及全部模型属性上下全宽，短项左右；实时配置和模型/资料手动草稿分离。失败保留/重试、外点关闭不穿透、最高层焦点、迟到读取/测试失效、单模型/搜索/Logo、直接测试/禁重复/结果返回均有方向约束。
- 字体/主题/正文外观通过原编辑实例更新，不丢 model、undo、cursor/comment；系统跟随仅两套色板。命令源合入运行时 Monaco 动作，所有平台绑定数组、逐项操作/显式空、菜单首键、作用域/前缀/别名/保留键冲突与原子转移规定完整；原型131条不冒充运行时全集。

## 机器映射独立核对

- `requirements-traceability.json`为91条计划要求，其中B/W/S/G/U/A/M/T/K/O分组共74条UI相关要求，均有实施模块和测试ID。B01–B07绑定原工作台/导航/AI区域/右面板/编辑器/令牌及演示排除；B08补模板入口。窗控/菜单、七分类设置、资料、智能体、模型/图标/直接测试、外观、快捷键、版本/反馈/文档均有具体条目，未用一个通用「设置」条目覆盖全部配置。
- `migration-map.json`含29面板、98工具、121路径、65服务、54数据模型。子代理定向核验29个Tab名称唯一且Tab/组件配对与`source-inventory.json`全部一致，每条有WEB-C01–WEB-C29测试ID；查看的原registry与该配对一致。prompts路径未列平台删除，GET/POST/PATCH/DELETE均迁为本地command；其余服务/数据库深层语义由技术综合审核和后续测试负责，本记录不冒称已运行它们。
- `reuse-manifest.json`为196条源文件记录。独立从Web基线commit读取：189个原`src/components`文件均有唯一处置记录，无漏项；196条SHA-256全部匹配该基线。平台排除限定管理员/营销组件，PromptsClient/shared例外为reuse；DashboardShell/SidebarTree/ChatPanel/ContentTabs/registry/CreateNovelDialog/ModelPicker/MarkdownEditor/Monaco及globals.css均绑定真实原文件。文件处置完整不等于189个全部复用，更不等于实际依赖已经可打包。
- 清单仍全为planned、证据为空；reuse状态为not-imported，未伪造代码/测试成果。正式测试文档必须把WEB-Cxx等组ID展开为原能力矩阵中的具体操作、状态与失败场景，不能仅证明Tab可打开。每次源组件改动还需填写manifest原因，并按允许差异与原Web同数据对照。
