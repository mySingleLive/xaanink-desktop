## 源码核对

- 模型配置使用独立草稿，添加时多选、编辑时单选，分类继承列表入口；保存前不进入确认列表，失败不修改旧记录。底部右对齐保存模型、测试连接、取消，无重试更新、默认用途和模型分类控件。取消/X/Escape 丢弃草稿；测试及停止测试保留草稿，不自动保存。
- 13 项供应商顺序、中文名称与用户要求一致。12 个本地彩色 Logo 加自定义通用图标；资源 SHA-256 与 `provider-logo-provenance.json` 全部匹配，MIT 许可文本保留，SVG 不包含脚本或远程引用。菜单上/下区截图确认完整选项可滚动访问。非自定义只显示 Key 与相应类别目录，自定义显示必要连接字段。目录与思考档位明确为示例，不证明真实兼容性。
- 模型目录与已保存列表不使用模型选择背景， checkbox/radio 表示选择；已添加项禁用以防重复。供应商菜单有 listbox/option 语义、方向键/Home/End 与 Escape 处理，Escape 先关菜单且阻止关闭模型对话框；最高对话框保持 inert 与 Tab 循环。
- 智能体位于模型上方，模型图标使用立方体 box。五项配置按顺序呈现，候选只取已保存、有效、启用、有 Key 且类别匹配的记录，图像不进入文本/审核候选。删除同时清除匹配默认引用并调整后续索引，不自动补位；失败保留待处理设置，重试重新核验引用。
- 用户资料的独立草稿、保存/取消、头像读取与解码会话隔离保留；其他即时设置不改为手动保存。Web 来源绑定与创作组件复用边界保留；静态稿不是实际 React 迁移证明。
