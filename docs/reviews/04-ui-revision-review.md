## 已核对的修订

- 默认 HTML 不再包含独立标题栏或底部全局状态条，工作台高度为整个视口。Mac 左导航头部严格按系统窗控、后退、前进、侧栏开关排序；Windows 右上角占位保留安全区。拖动区域与可操作控件的 CSS 区分明确。原型窗控为位置示意，原生行为仍待 App 验证。
- 设置分类为通用、用户、模型、界面、快捷键、关于我们；主容器没有保存/取消底栏。合法设置即时更新，失败保留待处理值，关闭不回滚；资料和模型另有校验及重试入口。子对话框下层 inert、最高层焦点循环；MOD-03 与 FOCUS-01/02 覆盖层级及关闭后返回对应触发按钮。
- 模型右侧只有列表及添加入口；配置进入独立对话框，供应商→协议→属性顺序清楚。八个指定供应商及 Qwen/MiniMax/自定义均覆盖，自定义必须选协议；主协议仅 OpenAI / Anthropic。Anthropic 输出/思考预算、OpenAI 附加字段及兼容端点模型差异体现。重截的模型子对话框图包含供应商标签、空 Key、输出上限及待补全状态。测试另行确认，原型禁止 fetch。
- 供应商、协议或端点改变即撤销原 Key；清除、停用、删除另行确认，确认后修改已确认记录和草稿，不会因关闭设置恢复授权。模型配置不回填明文，只记录示意 Key 状态。
- 用户卡片及独立资料编辑对话框存在；头像限制类型与大小，笔名非空，邮件可空并校验格式，资料不联网。独立查看资料子对话框、上传后卡片，USER-01–06 覆盖即时更新与输入保护。关于页标注 App 尚未发布，另标 UI v0.4，未虚构安装版本；反馈指向目标仓库新建 Issue，按用户回复预留 `https://xuanxiang.ink/docs`，未上线禁用。
- 主题为宣纸、玄墨、跟随系统三选一，底层仍仅两套色板。工作台小图增加标志、候选卡、正文和输入区，取代旧单色分栏，大窗/640px 截图可读。跟随系统通过媒体查询解析，取消独立开关。系统事件处理已读源码，但未切换真实系统外观取得交互证据，后续桌面测试须补齐。
- 快捷键搜索框在列表上方，恢复默认在同行右侧，移除底部编辑器说明；大窗/640px 图符合。KEY-01–10 覆盖搜索、空态、空值/冲突/保留键、即时更新与恢复默认。
- 作品目录逐次授权、已绑定拦截、迁移提交后关闭守卫、根失联、损坏备份禁止恢复及恢复稿保留当前正文逻辑继续存在。DIR-01–05、RECOVERY-01/02、MIG-01–03 是本次受影响流程的新回归记录，未直接沿用旧版检查结论。
