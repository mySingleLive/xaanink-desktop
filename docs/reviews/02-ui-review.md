## 检查范围及后续门

实际检查包括全部现有 PNG、静态 HTML/CSS/JS、资产来源，及 Chrome 中目录取消/下一作品、Key 撤销/取消、布局取消、快捷键录制、迁移前后/两平台目录、Escape、640px 导航与长标题等交互。检查使用演示内存状态，不验证磁盘写入、加密、模型调用、真实窗口拖拽或系统按钮，也不属于后续测试用例文档和 App 验收。

修复后须独立复审，记录每项关闭依据；随后由用户明确批准 UI。技术方案、TDD 实现与真实 Electron 测试仍必须按用户指定顺序完成。真实 macOS 与 Windows 安装、窗口/输入法、目录/恢复可靠性以及完整能力验收不能由平台切换截图或该浏览器原型代替。

## v0.3 最终复审结论

**UI 设计审核通过，UI-01–UI-10 已关闭；等待用户明确批准后才进入技术方案。** 本结论来自独立 UI 审核子代理在本次对话返回的复审意见，以下由主代理归档；不是主代理替代独立审核。

审核者原文结论：

> 收尾只读复核显示 v0.3 四哈希匹配，closeSurface(false/true)、new-chat、已绑定目录、syncModal/hideSub/Tab/Escape 与产品语义一致，未见剩余设计阻断，可关闭 UI-01–10。

### 复审方式与限制

v0.2 复审尝试通过 cua_repl；子代理的浏览器接口不可用，因此使用原生 Chrome，在实际复核中发现聊天取消授权与双模态 AX/焦点遗漏。环境中出现用户切换标签后停止在那里输入。v0.3 收尾采用已执行交互、冻结源码、新截图和主代理原型检查证据；审核者没有完整独立重放 129 项，不把主代理的执行记录冒充子代理独立执行。主代理通过内置浏览器 / cua_repl 单独补查了聊天取消重发、新聊天隔离、目录绑定、AX/焦点、迁移页面切换与恢复比较。
