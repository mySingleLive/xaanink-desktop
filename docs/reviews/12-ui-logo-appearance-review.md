# UI v0.8 模型图标、外观与调试工具独立审核

日期：2026-10-07（Asia/Shanghai）。审核者：独立 UI 子代理。前序产品 v0.7 本轮审核通过，见 `11-product-logo-appearance-review.md`。本轮范围为官方智谱图形、外观分类/无文字主题图、各模型项家族图标、独占行且默认显示的调试工具，以及相关选择和布局回归。

## 结论

**UI v0.8 独立审核通过，无遗留阻断项，可提交用户审核。** 四项修订在设计、源码与本版证据中一致；UI8-01、UI8-02 已关闭。主代理独占浏览器并执行 GUI 检查；本子代理独立审核源码、设计、原 Web 来源、19 张本地截图、检查记录与文件指纹，没有操作或重放浏览器。v0.7 的 58 项及更早检查不计为本版通过。

## 四项修订核对

- **智谱 Logo。** 本地 `providers/zai.svg` 为深色圆角块、白色 Z，与原 Web `provider-logos.tsx` 注明的官方 CDN 可见路径同源；本轮保留原配色、边框与圆角块，没有沿用 v0.7 的蓝紫色独立 Z。引用版本参数已更新为 v0.8。供应商清单单列官方地址、处理方法、前后指纹及品牌归属；不将其声明为 MIT 包内资源。
- **外观与主题图。** 设置分类、页标题和调试页面项使用「外观」。`miniTheme` 的标题和正文均为纯占位条，主题名/说明在图外；保留宣纸、玄墨、跟随系统三种选择规则及即时字号/行距/缩放设置。已独立看图的 `appearance-paper.jpg` 与此一致。
- **模型家族图标。** 配置目录、已保存两组列表、智能体三个模型触发器/选项及对话菜单共用 `modelLogo`。七份家族资产分别为 Claude、Gemini、Grok、Kimi、Qwen、混元、豆包；其余当前已核验示例复用对应品牌图形，GLM 使用新智谱块。自定义用通用图标，未按用户展示名猜测品牌。当前目录为演示夹具；正式应用仍按可信模型家族元数据与原 ProviderLogo 契约映射。
- **调试工具独占行。** HTML 默认不隐藏，初始化只有 `?review=0` 隐藏，Alt+Shift+P 可切换。body 使用纵向 flex，工具区域可换行且不收缩，App 占余下空间；工具不覆盖 App 窗控或弹层。已独立看图的 macOS/Windows 工作台均有单独工具行，正式 App 不包含此工具。

## 选择器、保存与隔离

- 智能体三个带图标下拉提供 combobox/listbox、标签关联、展开状态和选中状态。打开时聚焦可用选中项或首项，方向键/Home/End 跳过禁用项；按钮原生 Enter/Space 选择；Escape 关闭并返焦触发器，Tab 关闭后由触发器继续顺序导航，外部点击关闭。新菜单开启会关闭其他模型菜单和供应商菜单，设置重绘也会关闭旧菜单。K01–K06 与 R01–R11 的主代理 GUI 记录和独立看图对应，支持本版实际键盘焦点及短窗末项可达性结论；原生 Space 选择路径另经按钮源码核对，没有虚报单独 GUI Space 检查。
- 默认文本/审核只取已保存、启用、Key 已配置且字段有效的文本记录；文生图只取图像记录，空值/失效引用明确显示且不补位。提交仍走 `commitAgent`，失败写入待处理值并保留已确认配置，重试重新核验引用与思考档位。失效、删除及索引移动的原路径保留，兼容思考保留、不兼容回到模型默认。
- 对话菜单只列有效文本记录，提供模型图标、当前勾选及管理模型/空态入口。选择只同步当前模型字段，不写三个智能体默认，不重绘对话输入或正文，也不发送请求；当前会话与待处理默认值独立。新任务使用已确认默认值，不能使用尚未确认的待处理引用。原 Web ModelPicker 的思考子层与回滚/路由契约在最终复用范围内，当前静态原型仅演示本轮模型选择，不能据此删去原组件能力。
- 页面调试切换经 `go` 关闭模型/资料草稿；模型路径清计时器并递增编辑会话、测试批次标识，旧测试回调不能弹到新页面。平台/色板切换不重新绘制配置子对话框，保留草稿。首次启动调试场景明确重置演示记录；普通页面不把模拟重置施加到已保存记录。直接测试锁定、结果层 inert/焦点与返回原 DOM、资料显式保存/取消及迟到图片隔离未被本轮改写。

## 静态资源与验证

独立计算 7 个模型家族资产和 12 个供应商资产的 SHA-256，19 项均与各自清单一致。逐份解析 SVG，未发现 script、foreignObject、动态动画、事件属性或外部 href/src/url 活动引用。第三方声明明确区分 MIT 包来源的 7 个模型/11 个供应商图与官方 Z.ai 品牌资产；本审核不以项目许可证替代第三方归属。资源全部本地，HTML 仍以 CSP `connect-src 'none'` 禁止模型网络。

本子代理执行 `node --check design/desktop-preview.js` 和 `git diff --check`，均通过；菜单定位/返焦修复后再次检查 JS 语法通过，并补查 SVG 样式定义没有活动资源。主代理记录三份 JS 语法及 Git 空白检查通过，两者不混记为同一执行者。

## 发现与修复复核

UI8-01（已关闭）：主代理在 640×720 GUI 检查发现底部文生图菜单下边框被 settings-body 裁切约 5px，最后文字可见不等于完整菜单可达。现 `positionAgentMenu` 使用实际滚动容器可视矩形，选择上下展开并限制高度、移除重复间距；子代理源码复核通过。R01–R08/R11 与独立看图确认 640×720/640×560 的完整菜单、可滚动末项、Enter/Tab/Shift+Tab 可达。修复前裁切状态不计为通过证据。

UI8-02（已关闭）：子代理源码复核发现菜单只在打开时缓存定位，缩窗/工具显隐可能再次裁切；首次补上隐藏后，又发现模型与供应商选项焦点可能随隐藏回落文档。现 resize/工具显隐关闭菜单，且只在焦点仍属于打开菜单时先返焦对应触发器，外部已获焦目标不会被抢焦。R09/R10、B05/B06、K07/K08 的最终 GUI 记录与源码一致，关闭后设置值/模型草稿保留。此项只关闭浮层，不取消已确认配置或触发模型请求。

## 阶段边界

本审核仅覆盖 UI 设计与内存原型。Logo/选择器不证明真实供应商目录、输出/思考能力、Key 权限或接口兼容；没有真实模型请求、费用、磁盘原子持久化、Electron 原生窗控/系统拖动、安装包或真实 Windows 验收。工具行只属设计审核辅助。

用户仍须明确批准 UI，之后依原输出顺序进入技术方案、最终测试用例与 TDD App 实现。本次修改或产品审核不构成 UI 批准，也不构成最终 App 验收。
