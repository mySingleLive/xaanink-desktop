# UI v0.10 逐行设置、单模型与多快捷键独立审核

日期：2026-10-07（Asia/Shanghai）。审核者：独立 UI 子代理。前序产品 v0.9 已通过本轮独立审核，见 `15-product-settings-bindings-review.md`。依据 `03-ui-design.md` 第 10 节及 `desktop-menu-shortcut-contract.md` v0.2，审核每项一行、模型添加/编辑单选、每命令多绑定及相关焦点、失败、平台和菜单边界。

## 当前结论

**通过本轮 UI 原型独立复审，无剩余设计阻断项。** UI10-01–UI10-03 均已修复并经源码与本轮定向 GUI 记录复核。每项一行、添加/编辑单选和每命令多绑定与产品及契约一致，可交用户审核。子代理没有操作主代理独占的浏览器；本轮仅核对 v0.10 的 62 项检查和 21 张截图，不累计 v0.9 或更早通过数量。该结论不替代用户批准或实际桌面验收。

## 源码核对

- 设置新增统一分组和横向配置行；通用目录、备份和配置导入/导出各一行，主题为一行三选项，界面/正文各属性独立行，智能体五项各一行。用户编辑保持左头像、右属性布局，笔名/邮件各一行；模型属性横向排列。目录值带完整 title 提示；窄窗以两列继续保持左标签右控件，长说明折行和内容滚动。
- 模型草稿由多个 selectedIds 改为单个 selectedId，新增/编辑目录都为 radio 与非多选 listbox。搜索只过滤展示，不清草稿选择；候选解析返回零或一个型号，一次保存/测试只作用于该型号。供应商/类别过滤、重复禁选、Key 清除与测试快照/会话隔离不变。直接测试锁定目录和字段；结果返回同一配置 DOM，取消不提交。
- 每个命令的当前平台配置为有序数组，读时返回副本；仅 undefined 回退默认，显式空数组保持空。增加追加、编辑替换具体索引、删除只移除具体索引；锁定命令不可增删改。所有当前绑定参与搜索和作用域/别名/前缀冲突，编辑只跳过本命令本索引，其他绑定继续校验。菜单取第一项，集合为空不画键帽；其余绑定真实执行留实现阶段。
- 新增/编辑只在独立确认后提交，失败保留输入及旧集合；删除失败保留原项。取消/X/Escape 不提交；成功后恢复当前/相邻键帽或添加入口，搜索令该行消失则转搜索框。平台映射独立，切平台取消快捷键录制/恢复确认，保持模型/资料草稿；恢复确认仅重置当前平台。
- 最高层 inert/Tab、已消费事件与 IME 守卫、实时设置失败/待处理、用户头像读取会话隔离仍保留。本轮不因配置行重排改变已确认数据或真实 API 授权。
- 目录、供应商和智能体菜单改为视口 fixed 定位，但仍以对应配置内容区可视边界限制高度及上下展开。搜索及选项焦点使用 preventScroll；目录按完整 radio 所在行仅调整 catalog-list 的 scrollTop，另两类仅滚动各自菜单。真实祖先滚动关闭菜单并保留草稿；打开时记录祖先 scrollTop，忽略打开前排队但滚动位置未变化的旧事件，避免搜索时迟到关闭。

## 阶段边界

当前仅为浏览器内存原型，GUI 由主代理执行，子代理独立审源码/截图/记录。没有真实 Electron/Windows/macOS 原生菜单、磁盘持久化、系统多热键注册、完整 Monaco/IME、供应商网络/费用或两平台安装包验收；不会将原型通过称为完成 App。用户仍须明确批准 UI，再按原输出顺序进入技术方案、最终测试用例、TDD 实现和真实桌面验收。
