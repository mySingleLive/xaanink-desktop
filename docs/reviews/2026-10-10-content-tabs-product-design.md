# 右侧内容 Tabs 产品设计

批准记录：用户于 2026-10-10 明确表示“UI 设计审核通过，可以继续”，批准 `ink-xy-v4`。正式组件实现按独立技术/用例审核及专项验证顺序继续，无需重复请求 UI 批准。

本次将右侧顶部 Tabs 做成上下等距留白的小圆角矩形标签条。用户 2026-10-10 最新修订要求玄墨选中项参考附图提高高亮，并让拖拽预览同时跟随鼠标 X、Y 位置。小圆角矩形、普通箭头、上下等距留白、无红色强调边缘、无滚动条和长标题渐隐继续保留。玄墨选中项改为亮灰底色，覆盖此前所有主题选中背景与主体同色的要求；宣纸继续同色。用户审核 HTML 后，按本方案在真实 React 组件中实现；测试范围限本次 Tabs 及直接受影响的标题栏几何和操作。

## 视觉规格

| 元素 | 默认规格 | 行为 |
| --- | --- | --- |
| 右侧标题栏 | 44 DIP 高 | 沿用现有 Windows 标题栏高度；其他栏和原生窗控不改 |
| Tab | 32 DIP 高，上下各 6 DIP 空隙，圆角 6 DIP | 在 44 DIP 标题栏内居中；保留平直边缘和矩形轮廓 |
| Tab 宽度 | 按内容取宽，默认最小 96、最大 208 DIP | 受当前可用视口约束，视口小于最小宽度时允许缩到视口宽；字号增大也不能突破最大值 |
| 选中 Tab | 宣纸为 `var(--editor-bg)`；玄墨底色 `#2a2826`、描边 `#4b4640`、文字 `#ece7e1` | 玄墨参考附图提高亮度，选中项明显区别于暗色栏和主体；中性细描边，没有红色边缘或顶部强调阴影 |
| 未选中 Tab | 透明背景、弱文字；悬停轻染色 | 下方分割线连续；不模拟另一块主体 |
| 下缘 | 一条连续的 1px 分割线 | 位于气泡下方，与气泡保持 6 DIP 距离；不再被选中标签覆盖 |
| 标题 | 单行、末端 24 DIP 渐隐 | 只在实际溢出时启用透明度渐变；不追加省略号，不遮罩整项 |
| 完整名称 | Tab 的 tooltip 和可访问名称 | 包含正文、大纲、候选稿等后缀；保留完整原字符串 |
| 图标与关闭 | 固定占位 | 关闭按钮不被长标题挤走；悬停、选中或键盘焦点时清晰可见 |
| 鼠标 | 普通箭头 `cursor:default` | 标签、关闭按钮及标签菜单悬停都不切换为手形；拖动中也维持箭头 |

DIP 为桌面逻辑尺寸。Windows 下使用现有 `--desktop-caption-zoom` 换算，以保持原生栏对齐；固定最大宽度也按 zoom 换算，不随界面字号无限增大。其他平台沿用已有语义令牌，默认几何采用同一标签高度与上留白；HTML 的玄墨切换只审核主题，不代表 macOS 原生验收。

上下空隙留作拖拽区，标签、关闭、所有标签菜单及面板按钮均为非拖拽区。原生菜单、最小化、最大化、关闭及现有全屏、隐藏内容按钮的位置和安全区沿用当前实现。Tabs 在标题栏内居中，不移动这些按钮。键盘焦点使用中性轮廓，避免重新出现深红色气泡边缘。

## 溢出与标签操作

标签条始终单行，不显示横向或纵向滚动条。宽度不足时，视口裁切屏幕外标签；激活、聚焦或调整窗口和分栏大小后，使目标 Tab 完整进入视口。仅在发生溢出时，面板工具组前显示向下箭头，名称为“所有标签”。弹出菜单列出全部已打开项，当前项显示选中标记；长名称在菜单中换行，供用户查看完整标题并切换。菜单可有自己的纵向列表滚动，标签条下方没有滚动条。

支持触控板横向移动及 Shift 加滚轮；普通纵向滚轮不劫持正文滚动。左右方向键移动标签焦点，Home/End 到首末项，Enter/空格激活。保留鼠标点击激活、中键关闭、关闭按钮以及关闭当前项后现有 store 的相邻项选择规则。所有标签菜单支持键盘打开、方向键选择、Escape 关闭和焦点返回。

鼠标左键按住标签的标题、图标或空白区域，移动至少 6 DIP 后进入排序。显示半透明标签预览和中性插入线，保留按下时鼠标到标签左上角的 X、Y 偏移，两个方向都随鼠标移动，无进入拖动时的位置跳变；原位置保留淡化占位。预览允许移出标签条，插入线保持在其上方且不拦截鼠标。拖到目标标签前后并松开后，标签按插入位置重新排序，中间项顺移。拖动未选中项只调整顺序，不切换正文；拖动选中项仍保持该项选中。关闭按钮不启动拖拽。

鼠标停在标签视口左右边缘时，视口自动横向移动以触及屏幕外项，不显示滚动条。只允许在标签视口内落下；拖到正文、工具或窗控区域后松开不改变顺序。Escape、指针取消、失去捕获或窗口失焦取消拖动，清理预览和插入线。拖动结束的 click 被拦截，避免误激活；普通点击仍按原规则工作。

仅当前打开的标签顺序改变，不新增跨重启的排序持久化。菜单同步排序后的顺序；关闭当前标签按新顺序选择相邻项。正式组件保持原 `tab.id` 和业务 map/key/hidden 结构，拖动不能重挂载编辑器、改变草稿或触发离开当前场景的 guard。HTML 预览中排序也不重建主体节点。键盘除保留原导航外，提供 Alt 加左右方向键调整当前焦点标签顺序，播报排序位置。

在右侧视口不足以容纳一个完整标签、但仍可容纳工具组时，所有标签菜单仍须可达。原生安全区和面板按钮优先，视口允许降到 0，菜单仍能选择和关闭项；不能把工具按钮推进原生窗控。若工具组本身也超出可用空间，批准后细化保持安全区的紧凑布局；分栏收起动画中的零宽度不能承诺区内交互，此时沿用左树或对话区的恢复入口。本审核稿的窄面板为 430 CSS px，不将其预览结果推及所有极窄尺寸。该边界在批准后的专项测试中验证。

空 Tab 状态沿用真实空态文案和隐藏面板入口，不额外放示例作品。切换、关闭、窗口伸缩、主题改变不改业务内容和数据持久化规则。未激活的面板保持现有隐藏实例结构，保留编辑器、草稿和撤销历史。

## HTML 审核稿

入口：`design/content-tabs/index.html`。展示右侧面板的正常与窄宽度、宣纸与玄墨、少量与大量标签，以及长标题渐隐。可点击切换、关闭标签，打开所有标签菜单，用鼠标拖拽重新排序，并用键盘移动。全部标题为明确的设计示意数据。原生窗控为不可操作的视觉占位，不计真实 Electron 验证。

重点审核：玄墨亮灰选中高亮、鼠标二维跟随、小圆角矩形、上下各 6 DIP 留白、普通箭头、排序、标题渐隐、208 DIP 上限及溢出入口。顶部审核工具在产品区域之外，不进入正式界面。前三版设计分别保存在 `design/content-tabs/archive-v1/`、`archive-v2/` 和 `archive-v3/`，仅用于历史对照。

## 技术落点

1. `ContentTabs.tsx` 仍承担真实业务。标题栏外层保留 caption 数据和安全 padding；内部独立的 tablist 视口与工具组分离。移除局部 `top-px` 位移和 `truncate`，使用受控溢出状态及标题 mask。
2. 样式采用局部类，将 Tabs 视口在 44 DIP 栏内居中，避免影响 ChatPanel、SidebarTree 或通用 UI Tabs。底线连续绘制、气泡与上下边界等距；移除顶部红色强调阴影，缩放后通过几何和截图验证。
3. ResizeObserver 观察视口及标题尺寸；Tabs 数量、标题、激活项、字体加载和字号变化均触发测量。发生溢出才显示菜单，预留其实际宽度后重新计算；不因显示入口造成循环抖动。
4. 显露只调整本地视口的 `scrollLeft`，不让 `scrollIntoView` 滚动外层工作台。内部 mask 只在 `scrollWidth > clientWidth` 时启用。
5. 复用仓库现有 DropdownMenu 构件和 store 的激活、关闭能力；不复制 29 类业务面板、不新增服务、不更换内容 registry 或 store 的持久化格式。
6. `requirements-traceability.json` 与 `migration-map.json` 增加本次设计阶段记录。正式完成状态在批准后的实际结果产生后更新，不修改旧的全量失败记录。
7. 现有 `src/stores/tabs.ts` 无重排操作。批准后新增只调整 `tabs` 数组顺序的动作，以 id 校验移动目标，保持 activeTabId、activationNonce、subTabs、panelFocus 和 Tab 对象身份，不经过场景离开逻辑。拖拽监听仅位于非窗口拖动的真实 Tab 区，关闭按钮除外；取消与卸载释放监听、指针捕获和动画帧。HTML 用 Pointer Events 捕获做无依赖示意，不能把局部 tabs 数据复制进正式组件。
