| 文本/文生图供应商筛选 | 按已核验的输出类别筛选，不把图像输入能力当作生成能力；自定义保留但不承诺其能力。调研列出当前十二家文本、八家文生图的依据，明确当前排除仅表示未核验到对应预设，不能断言供应商永无该能力。安装版须更新能力目录并核验 Key 权限。通过。 |
| 完整目录与可用性 | 产品、调研与预设仍要求完整匹配类别目录、全部分页及权限/认证/网络状态；公开目录不能冒充授权全集。权限未知不得称可调用，单项或选中批次测试不能验证未测型号。目录夹具为 demo，真实发现与兼容核验尚未完成。通过。 |
| 直接测试与批量范围 | 产品明确点击即启动，无测试前确认/目标选择框；当前配置框持续显示已选数量、请求范围和可能费用。多选冻结草稿逐项测试全部所选，每项文本短回复或一张图片。结果逐型号呈现型号/供应商/端点及成功或错误；关闭结果返回原草稿，不自动保存或修改智能体。预设与 D03 一致。通过。 |
| 加载动画与禁止重复 | 测试按钮旋转并显示进度，整批结束前禁用，同时锁定字段及保存；不让一次批次在过程中更换目标或提交配置。结束后测试恢复可再次使用，结果弹层是完成后的反馈。通过。 |
| 取消与迟到隔离 | 测试时取消/X/Escape 关闭配置、取消在途及剩余项目；草稿会话/批次隔离迟到结果，关闭或新开编辑不会被旧批次重新弹结果。保存/取消契约仍保护已确认记录和旧授权，测试结果不提交模型。通过。 |
| 供应商能力与权限分离 | 供应商被筛入只表示有核验过的对应输出能力，不代表所有型号或当前 Key 可用；模型按真实能力、端点/区域与权限核验。隐藏 OpenAI/Anthropic 标记不能替代实际图像接口适配。更换 Key 不沿用旧权限验证状态；智能体仍只取已保存有效且类别匹配的记录。通过。 |
| 腾讯文本与图像边界 | 文本表指定混元 API Key 与 `api.hunyuan.cloud.tencent.com`；调研和预设额外明确文生图采用 TokenHub 国际站的 API Key、图像端点及 wand 路径，不能沿用混元文本服务凭据/地址或旧云签名。该类别覆盖规则与通用文本预设表不冲突。通过。 |

## 腾讯官方依据定向核对

本次读取的 [腾讯 Hy 生图调用指南](https://intl.cloud.tencent.com/zh/document/product/1300/83708)（页面标注更新于 2026-09-22）明确要求 TokenHub 控制台 API Key、Bearer 鉴权以及模型开通，列出 `tokenhub-intl.tencentcloudmaas.com` 下的 wand 生图接口。该事实支持文档将图像服务与混元文本预设分开，不能据供应商同名复用授权。这里只核对公开接口边界，没有证明当前 Key 权限、完整发现能力或真实调用成功。

## 保留的后续边界

真实测试行为和费用授权留待正式 App 阶段；本阶段不联网的模拟结果不能称为供应商可用性、全目录发现或 App 验收通过。产品仍保留本地数据、用户模型、Key 加密与脱敏、候选/草稿保护、独立目录、稳定能力映射及两平台真实验收要求。无前置弹框是用户本次明确要求，旧审核中的测试前确认要求属于历史版本，不应重新加回当前交互。

本审核没有提前产出下游交付物。产品通过后仍要完成独立 UI 审核并取得用户批准；技术方案、最终用例、TDD 实现及全部真实桌面验收尚未开始。
