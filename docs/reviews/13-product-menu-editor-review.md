## 作用域、输入法与草稿边界

补充契约以菜单打开前聚焦的实例/输入为编辑目标，不能因为菜单抢焦就把操作路由到别处；只读预览不允许剪切/粘贴修改。正文仍复用原 MarkdownEditorHandle、编辑命令和 Monaco 撤销/自动保存/版本契约，应用菜单不越过候选稿批准。

快捷键冲突按作用域及同时激活条件判定：全局与局部冲突，同类输入冲突，互斥输入场景可复用；共享编辑 ID 的菜单/输入绑定不是两条独立命令。IME 组合期间不触发发送/菜单/热键；已被菜单/对话框消费的 Escape 不再停止任务。平台切换不覆盖另一平台绑定，录制与恢复默认取消保留已确认值。这些规则和原有草稿保护目标一致。

模型下拉、图标、字体与菜单均属于用户授权的本轮桌面差异；文本/文生图分类、已保存模型引用、Key 授权、独立草稿提交/取消、批次测试不保存和完整目录承诺没有因呈现变化而放宽。D03 对应模型下拉/参数，D04 对应外观及作用域快捷键，D05 对应两平台菜单，未错误占用原备份或独立安装能力 ID。

## 验证限制与继续条件

文档诚实限定当前原型：macOS 桌面条是审核示意，浏览器不能证明原生菜单/窗控；静态快捷键表仅代表性动作，不能证明完整 Monaco 注册或执行；不注册系统热键，不操作真实剪贴板/生成接口、原生退出或磁盘保存。原生菜单焦点、编辑命令、真实字体/键盘布局/IME、辅助功能及两平台安装包必须在用户批准 UI 后进入最终用例与真实 App 验证。

本审核确认产品范围和可观察行为定义，并不确认这些最终能力已实现或测试通过。UI 用户批准门仍有效；此次没有提前生成下游技术、测试或实现产物。
