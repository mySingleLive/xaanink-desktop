## 已核对的实现边界

- 文本/文生图列表、计数与空态独立；配置继承入口类别，添加/编辑一次只选择一个模型。预设供应商TEXT为12家+自定义，IMAGE为8家+自定义。图像菜单过滤不证明所有目录adapter或图像调用已实现；39明确保留不支持/不完整范围。
- 供应商优先；预设只显示Key与目录，自定义显示供应商名、协议、展示名、BaseURL、型号、Key及可选高级上下文。密码框不回填；同范围空Key交main复用，改供应商/协议/地址清草稿Key与旧能力。目录身份、数量、完整性与权限由main提供，UI明确提示不完整及列出不代表可调用。
- 目录支持搜索/单选/已添加项禁用。编辑当前已保存型号可保留；刷新缺失不删除旧记录，不自动改成另一型号。重复检查最终仍由main原子写入再校验，UI检查不构成安全边界。
- 测试直接开始，无前置确认框；说明短文本或1图费用。busy冻结字段/保存并拒绝重复请求；X/取消/Escape或设置外点终止本会话。操作ID与alive守卫阻止迟到结果进入重开的草稿；取消IPC rejection被消费。结果冻结供应商/端点/型号，不保存配置，不修改全局默认，返回结果只关结果层。
- 模型保存先复制草稿，保存/设置/删除共用一条队列，每次以最新确认revision构造动作；无回执不发布可选择模型。失败保留草稿/旧记录，成功后清旧错误。独立测试9执行真实Zustand store与受控IPC，确认7→8→9三动作串行，不使用三份独立队列。
- 智能体仅从对应类别已保存记录选择；无默认与失效默认明确，停用保留失效ID，删除清引用，不补位。新默认不强改当前会话。思考标签复用原能力解析；metadata是来源声明，不以某Logo或protocol标签证明能力。
- 本地品牌资源20份（12供应商、8家族）SHA256全部匹配批准设计provenance，独立检查未发现script/事件属性/foreignObject/外部或data资源。智谱保留官方黑底圆角Z、GPT家族纸黑墨白、Kimi家族黑块；其他已知家族映射，未知/自定义用通用图标。MIT包和官方品牌归属分开，未将官方资源宣称MIT。
