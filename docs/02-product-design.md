## 1. 产品目标与验收范围

为作者提供独立、可安装、完全管理本地数据的玄印写作桌面 App。独立公开仓库为 `mySingleLive/xaanink-desktop`。技术栈为 Electron + 现有 Next.js / React / TypeScript 等 Web 栈，所有创作界面复用 Web 版。

交付目标为功能完整的桌面迁移，不以原型、仅包装 Web 网站、在线登录或精简 Markdown 编辑器代替。macOS 与 Windows 均属于验收范围。

| 需求 ID | 要求 | 可观察的验收标准 |
| --- | --- | --- |
| R01 | 独立开源项目 | 新仓库独立安装、构建、测试、打包；无父目录依赖；包含许可与来源记录 |
| R02 | Electron + 原 Web 栈 | 安装包启动 Electron；原创作 React 组件/业务模型迁移并可用 |
| R03 | 只使用用户模型 | 空配置不发 AI 请求；任何 AI 路径只调用用户端点/Key；删除或失败不回退平台 |
| R04 | UI 一致 | 原导航、对话、面板、编辑器、主题、SVG 标志；差异仅桌面窗控/导航、本地身份/路径与设置 |
| R05 | 原生无边框窗口 | 顶部可拖拽；macOS 左系统交通灯；Windows 右系统按钮；支持关闭/最小化/最大化或全屏/恢复 |
| R06 | 本地应用数据 | 默认位于家目录 `.xuanxiang`；修改根目录可安全迁移、失败恢复，不访问平台数据服务 |
| R07 | 每作品指定目录 | 每部作品创建前显式指定独立目录，正文/设定/附件/历史留在该目录；重定位后可完整打开 |
| R08 | 用户设置 | 通用、用户、智能体、模型、外观、快捷键、关于我们；有效设置即时更新，用户资料/模型独立保存；重启保持 |
| R09 | 无部署服务 | 干净机器安装即可启动；无 Node/数据库/Docker 配置、无本地 HTTP 监听、无远端 Web 服务依赖 |
| R10 | 顺序与审核 | 所有产物依次产出，各指定阶段有独立子代理审核；UI 用户批准后进入技术阶段 |
| R11 | 真实用户验收 | 全部用例执行且有证据；真实 Electron App 两平台操作通过；未运行/跳过不得计通过 |

## 3. 首次启动与日常流程

首次启动进入与 Web 相同的「侧栏 + 对话」初始工作台；没有独立标题栏或底部全局状态栏；分栏贯穿整个窗口。侧栏底部使用 Web 原账号菜单触发器，显示本地头像、笔名和邮件；点击打开向上的菜单，其中添加「设置」。去掉用户名右侧齿轮。无需账号登录。首次启动中央不提供添加模型按钮；仅在实际执行 AI 任务且缺少所需模型时弹出引导（见第17节）；手动创建、编辑、导入与导出仍可使用。

首次启动自动创建默认数据根目录并校验可写。目录无法创建时，显示原因与「选择其他目录 / 重试」；不假装成功、不重置数据、不自动跳到未知临时目录。

日常流程：打开作品 → 选会话/正文/设定 → 原 UI 编辑或调用作者配置模型 → 自动保存并显示真实回执 → 关闭并再次启动恢复作品、布局、标签与草稿。设置和原生文件对话框不导致编辑实例重挂载或丢草稿。

## 4. 作品与目录

### 4.1 统一创建流程

保留侧栏「创建作品」和对话选择器中的同义入口，均进入现有单页向导。向导增加底部「作品目录」行，必须通过系统目录选择器选择。只预填建议路径，不自动视为已确认；支持中文、空格与 Unicode 路径。

未关联作品的对话还可通过现有 `startNovelFromChat` 提出建书。此入口也必须先打开同一作品目录授权行，由作者通过原生目录选择器明确确认；与向导复用校验、幂等回执及本地事务。AI 提议不能绕过目录步骤或自行在建议/默认路径建书；未选择目录时返回待确认状态、不写盘。

原 Web 向导的「确定」只生成草稿、不自动发送。桌面提供：

- 「放入对话草稿」：保留现有模板拼贴与延迟建书语义，挂起已授权目录与创建请求。首条发送先完成本地建书回执，再开始模型请求；模型未配置或调用失败不删除已经创建的作品。
- 「创建并手动写作」：作者无模型或离线时也能新建。显式创建本地空作品，将同一模板草稿保留在关联会话，不自动调用 AI，然后打开作品概览。

不恢复书名输入步骤；使用当前兜底命名规则，书名可在作品概览修改。目录路径独立于书名，重命名不会移动文件夹。

### 4.2 校验与回执

接受空目录，或通过「打开已有作品」明确识别的本应用目录。非空且不是本应用作品目录时拒绝创建，提示另选/新建子目录；不删除或覆盖已有文件。目录已绑定另一作品、只读、空间不足、被其他实例占用或位于另一作品内部均提示具体原因。

「放入对话草稿」在选择时进行校验，在实际建书前再次验证。取消向导/清空挂起请求不在磁盘遗留已创建的作品。重复点击、重放同一建书请求只创建一次；建书失败保留草稿和用户选项，并可重试。

项目使用唯一作品 ID，与目录名和展示书名解耦。同一作品不允许双实例并发写；第二实例聚焦已有窗口或以只读方式打开并说明原因。

### 4.3 打开、移位与删除

支持打开本地 manifest 目录、重新关联已移动目录、从作品阁移除索引、整部作品备份/恢复及导出。外置盘失联的作品显示「目录不可用」，保留索引和未保存草稿，不自动新建同名空作品。

设置中的应用数据目录迁移不搬动作品。作品需要移动时使用「移动作品目录」，保存草稿、暂停任务并校验后复制/切换，失败仍使用原目录。直接在文件管理器移动后可重新关联。

默认删除行为仅移除作品阁索引或归档；删除本地文件属于单独明确操作，显示完整路径与影响，按系统回收站能力处理。恢复失败不覆盖健康作品；不从 App 静默递归删除目录。

## 5. 应用数据根目录

| 系统 | 默认路径 |
| --- | --- |
| macOS | `~/.xuanxiang/` |
| Windows | `%USERPROFILE%\\.xuanxiang\\` |

保存通用/UI/快捷键配置、本地模型元数据和密钥密文、全局模板与提示词、作品索引、应用日志/恢复状态。每作品实体、正文、会话、候选、历史和附件在该作品目录保存；无作品关联的对话草稿与模板在应用根目录。

迁移步骤（按第17节新版）：通用页持续显示当前根、预计数据大小、作品目录不移动与旧根清理范围 → 点击迁移打开系统目录选择器 → 用户选择目标并以「选择并迁移」确认本次操作 → 检查可写/容量/目标冲突（失败不启动） → 展示进度并开始迁移 → 暂停任务并落草稿 → 一致性复制和验证 → 在新根保留迁移前恢复快照 → 提交新根并恢复 → 清理旧根中本应用管理的配置/密钥密文/数据库/日志 → 显示成功。不再另设进度页的执行确认；用户在选择器确认前可见该清理范围，作品目录与未知文件不在范围内。进行中可停止在提交之前，失败保留旧根且可重试。

迁移成功时，旧目录本身保留但本应用数据不留副本；默认根目录只保留发现新根位置的引导指针与最小迁移恢复记录。恢复快照位于新根，由备份保留策略管理且密钥始终为密文。旧根清理失败时显示「新目录已启用，旧副本清理待完成」及残留范围，可重试；此时不能宣告完整迁移通过。系统凭据保护与安装信息依操作系统规则存放。

重复迁移通过同一引导指针定位当前权威根，不从历史根合并数据。新根失联时进入定位/恢复界面，保留指针；不能自动启用旧副本或创建空配置假装原数据已恢复。

## 6. 模型管理

主页面只显示「文本模型」「文生图模型」两组已保存列表；各自添加入口确定新模型类别，配置框不再提供「模型分类」或「默认用途」。图像理解仍属文本能力，文生图只指图像生成。模型行无高亮选择背景；两类会话选择独立，选择图像不能替换文本模型，删除不静默补位。模型项图标为立方体。

添加/编辑打开「配置模型」，先选供应商。预设为 OpenAI、Anthropic、Google、xAI、深度求索、月之暗面、智谱、Xiaomi、阿里巴巴、MiniMax、腾讯、字节跳动，另有自定义。每家左侧使用对应彩色 Logo；智谱采用 z.ai 官方黑底圆角块、白色 Z 图形。供应商按已核验目录的输出能力筛选：文本入口只显示有文本输出模型的供应商，文生图入口只显示有图像生成模型的供应商；图片输入不算文生图能力。自定义在两类入口保留，由作者配置目标并验证实际能力。非自定义只显示 API Key 与该供应商模型列表，协议/端点/参数按预设和实际能力管理，不显示复杂字段。自定义显示名称、OpenAI / Anthropic 协议、展示名、Base URL、模型 ID、Key 和必要上限配置。预设范围、区域与官方依据见 `provider-ui-presets.md`；其他区域/特殊端点使用自定义配置。

安装版目录覆盖所选供应商端点和 Key 权限下全部匹配类别的模型，处理完整分页、目录刷新、认证/权限/网络失败。公开目录不能冒充授权全集，不支持授权发现的供应商展示官方完整目录与「权限待验证」状态，逐项显式验证后才宣称可用。不得用示例、精选型号、名称猜测或第一页替代完整目录。技术阶段逐供应商核验发现能力；当前仅设计夹具，不是已实现的真实目录。详细边界见 `provider-catalog-research.md`。

添加允许勾选多个模型，一次保存；编辑一条记录只选择一个型号。已有记录标为「已添加」并阻止重复添加。没有模型选择高亮背景，勾选控件仅表达待保存选择。无匹配模型、目录加载/失败/权限未知有明确状态；刷新不删除已保存记录。模型能力按真实元数据验证，图像输入不当作图像输出。

底部按钮固定为「保存模型 / 测试连接 / 取消」，右对齐，无「重试更新」。打开时复制已确认记录为独立草稿；所有字段和模型选择在保存之前不更改列表或智能体选项。保存校验 Key、模型、端点与能力，原子提交批量记录；存储失败保留草稿/旧记录，再点击保存。取消/X/Escape 丢弃草稿。未完成新模型不进入已添加列表，重开从确认数据或空白新草稿开始。

Key 保存后才加密落盘；未保存 Key 只留在临时草稿，允许作者显式测试，取消后清除。编辑不回填明文；留空保留同一授权范围的确认 Key。更换草稿供应商/协议/端点清空草稿 Key，禁止跨端点沿用；取消编辑不撤销旧记录。成功提交授权范围变更或更换 Key 时才撤销旧授权并取消旧请求；同供应商/端点更换 Key 也增加授权版本，后续调用不沿用旧 Key；新 Key 不沿用旧权限验证状态，目录/权限需重新发现或明确标注待验证。导出配置强制不含密钥，日志和错误脱敏；系统凭据保护不可用时拒绝保存，不降级明文。

选择供应商并输入 Key 后，安装版只向该供应商发现目录元数据；不自动生成文本或图片。「测试连接」在配置框内直接启动，不再弹出测试前确认或目标选择框。当前框持续说明已选数量、请求范围与可能费用；多选按冻结的草稿逐项测试全部已选型号，文本每项短回复，文生图每项 1 张图片。按钮显示旋转动画与进度，禁用至整批结束，同时锁定字段及保存；取消/X/Escape 关闭配置并取消在途与剩余项。完成后弹出逐型号结果，含型号/供应商/端点/成功或错误；关闭结果返回原草稿，测试按钮可再试。测试不保存模型、不更改智能体默认值，也不证明未测型号可用。会话/批次隔离迟到结果。原型全部模拟，不联网；正式真实调用另行授权。

HTTP 仅允许作者显式配置的本机回环地址，其他端点要求 HTTPS；拒绝 URL 内凭据。跨域重定向不携带 Key；额外代理/资源来源必须作者显式配置。每次请求持有不可变配置快照，后续子任务、摘要、重试取最新授权版本。成功保存普通名称/参数修改不改已发请求；提交授权范围变更，或显式删除/禁用/清除 Key，立即取消旧请求和后续调用，提示任务暂停并保留草稿/候选。关闭设置不复活授权，不静默替换模型。

默认创作/审核/文生图模型移至「智能体」；其他 AI 用途依原 Web 路由契约指向作者本地记录。Auto 若保留只能在作者明确配置的模型/端点中工作，不沿用平台 Auto 或计费降档。

## 7. 设置界面

从原侧栏底部用户名菜单的「设置」与 `Cmd/Ctrl+,` 打开设置；关闭回到原工作台状态。分类顺序为「通用 / 用户 / 智能体 / 模型 / 外观 / 快捷键 / 关于我们」。设置独立于作品设定与对话设置。

| 分组 | 内容 | 更新行为 |
| --- | --- | --- |
| 通用 | 应用数据目录、默认作品父目录、启动恢复、备份、配置导入导出 | 合法变更自动保存；迁移/恢复另行确认执行 |
| 用户 | 头像、笔名、编辑按钮；独立编辑对话框含头像、笔名、邮件 | 仅本地资料；编辑对话框左右布局，左侧头像占满表单高度并可点击选择图片，右侧笔名与邮件；点击保存后原子更新，取消/X/Escape 丢弃未保存资料及头像；无账号或邮件发送 |
| 智能体 | 默认模型、默认模式（标准/计划）、默认思考强度、默认审核模型、默认文生图模型 | 即时更新；模型仅来自已保存且启用/有效授权的对应类别；思考仅实际支持档位；用于新任务，不改当前会话或在途请求 |
| 模型 | 文本/文生图列表、立方体图标；独立供应商优先配置 | 保存模型/测试连接/取消右对齐；仅保存提交，测试不保存，取消丢弃；无默认用途/分类字段 |
| 外观 | 主题三选一：宣纸、玄墨、跟随系统；界面字体/字号/缩放，正文支持字体/字号/行距/行号/默认不换行，布局恢复 | 即时响应并自动保存；只有 paper / ink 两套色板 |
| 快捷键 | 上方搜索框及同行右侧恢复默认，下方菜单/Markdown/AI/普通输入命令列表，按作用域录制/冲突检测 | 有效绑定即时更新；不再显示底部编辑器说明 |
| 关于我们 | 实际安装版本、填写反馈、查看文档 | 用户主动打开系统浏览器；文档尚未上线时禁用 |

不显示底部「保存设置 / 取消」，不出现分组切换的脏状态确认。输入校验失败保留待修正内容，不替换上一有效配置；自动持久化失败提示原因、保留待处理修改并提供重试。关闭或切换不会回滚已确认变更。模型和用户编辑的独立草稿在取消时丢弃；保存失败留在当前编辑框修正或再次保存，不写成已添加记录。最终实现必须将此规则落到本地原子回执，原型的内存更新不计为持久化通过。

关于页版本来自实际安装包 `app.getVersion()`，不得手写 UI 稿版本作为 App 版本。当前 App 尚未发布，设计稿显示「尚未发布」。反馈指向 `https://github.com/mySingleLive/xaanink-desktop/issues/new/choose`。按用户 2026-10-07 回复，帮助文档预留 `https://xuanxiang.ink/docs`，上线后启用；当前禁用并标注尚未上线，不自动探测或访问。

默认快捷键：设置 `Cmd/Ctrl+,`；保存 `Cmd/Ctrl+S`；创建作品 `Cmd/Ctrl+N`；新对话 `Cmd/Ctrl+Shift+N`；查找沿用编辑器；关闭当前 Tab `Cmd/Ctrl+W`（编辑器无 Tab 时才交由窗口约定）；应用退出沿用系统。IME 组合输入阶段不触发发送或命令；修改绑定后帮助和菜单一起更新。

## 8. 视觉与窗口行为

只允许 `paper` / `ink` 两主题。系统跟随只是选取这两主题的规则，不形成第三主题。UI 使用原 `globals.css` 令牌、Base UI/shadcn 按钮与表单、Lucide 图标、温玉原生 SVG。正文保留纸纹；玄墨界面表面保留墨石纹理。

取消独立标题栏和底部全局状态栏。左导航、中对话、右内容从窗口顶部到最底部，分隔线贯穿全高。macOS 系统交通灯直接放在左导航顶端，右侧顺序为后退、前进、侧栏展开/收起。侧栏收起及窄窗时在当前面板顶端保留系统按钮与导航入口。Windows 原生窗控位于右上角当前面板头部安全区，不压住内容 Tab 或操作。

顶端各栏头部空白可拖动，按钮、输入、菜单是非拖拽区；没有另加横贯窗口的拖拽带。后退/前进沿当前窗口的已打开视图历史导航，切换不丢编辑草稿；历史边界禁用按钮。全屏/缩放/系统控件可达性在两平台真实窗口验收。

初始工作台仍为两栏；内容展开后侧栏初值 260px，对话与内容按原逻辑首次均分。窄窗沿原面板切换策略处理，不改变为新仪表盘。保留原面板拖拽、Tab、评论、原子 chip 与草稿状态。

macOS：红色关闭窗口，黄色最小化，绿色由系统支持全屏/缩放；关闭最后一个窗口后符合 macOS 应用生命周期，可通过 Dock 重开。Windows：右侧原生最小化/最大化恢复/关闭组，支持系统吸附。关闭前等待保存，保存失败提供「重试 / 导出草稿 / 取消关闭」。有生成任务时明确询问是否停止并退出；不悬空写入。

## 9. 数据可靠性与隐私

写入仍遵守版本检查、操作幂等、事务快照、评论锚点、候选批准和定稿边界。自动保存按真实本地回执更新「已保存」，错误显示原因并保留草稿。外部修改产生冲突时比较并明确选择，不静默覆盖。

后台备份不阻塞输入；备份含作品数据库与附件，一致性校验后才宣告成功。备份失败提示且不删除旧备份。崩溃重启提供草稿恢复；正常关闭落盘。全局与作品 schema 升级先备份，失败保留原数据并进入恢复界面。

运行时不连接玄印写作平台、遥测、CDN、在线字体、自动更新或登录服务。文档链接/开源仓库仅用户主动打开系统浏览器时访问。导入 Markdown/图片/备份不能获得任意文件访问或代码执行能力；日志不含正文、请求体或 Key。

## 10. 发布与完整验收

交付可独立构建的源码、锁文件、许可证/第三方声明、macOS（Apple Silicon 与 Intel）和 Windows x64 打包配置。实际支持的每个发行产物必须记录构建、启动和安装验收证据；不能以交叉打包成功代替目标系统运行。

每个 Rxx 映射到后续测试用例及证据；真实桌面用户场景至少覆盖：无模型首次启动、指定作品目录、人工离线创作、用户 Key AI 对话/候选/评审、批准后落稿、图像与附件、窗口拖拽/按钮/输入法、主题/布局/设置保持、数据迁移、异常关闭恢复、备份恢复与独立安装。

UI 必须先经子代理审核并交由用户确认；用户批准后才进入技术方案。技术、测试、代码各有指定子代理审核。最终所有用例通过且两平台真实验收通过后再输出完成总结；环境、端点或机器缺失要明确列待验收，不能标记完成。

### 本次 UI 复用与资料提交约束

除用户明确指定的桌面窗控/导航、本地数据/模型设置与本地用户功能外，布局、主题、组件、面板和交互完全沿用现有 Web UI，不能因桌面迁移重设计创作功能。原账号菜单的触发器、用户标签、外观行和开关保留；Web 登录、退出登录与管理员链接按既有平台能力排除，新增菜单中的设置仅打开本地设置。实际 App 复用原 React 组件，静态设计稿不视为已经完成组件迁移。

用户编辑与模型配置是即时设置的明确例外。用户编辑：打开时复制已确认资料为独立草稿；文字、文件预览不修改侧栏或用户卡片。保存校验后一次提交头像/笔名/邮件；存储失败保持对话框和草稿、展示具体原因，旧资料继续使用。取消、X、Escape 都销毁草稿并使迟到文件读取失效。重新打开从已确认资料开始。模型按第 6 节独立提交；其他设置仍按即时更新规则处理，设置主窗没有全局保存/取消。

智能体引用采用稳定模型 ID（静态稿索引只作演示）。未配置有空态，停用/移除/失效显示待重选而非静默替换；默认文本/审核不能选文生图，默认文生图不能选文本。切换不支持原档位的默认模型，将思考重置为模型默认并明确显示；保存失败保持已确认配置，重试前重新核验引用与能力。默认模式/思考/审核/图像只作用于新任务，继承原会话和任务边界，不绕过作者批准。正式 App 思考选项复用原 `src/lib/ai/thinking-effort.ts`，不对所有供应商硬套档位。


停用是可逆管理操作：列表提供显式「启用」入口，核验已有 Key 与字段后恢复该记录可用性；不自动改选其他模型，也不启动请求。先前对同一模型的默认引用可恢复有效，思考使用模型默认；删除不恢复引用。启用写入失败保持停用。

## 17. 桌面交互修订（v0.11）

主题移动到外观页「界面」分组的第一项；其他界面、正文分组与行布局不变。本轮优先于旧稿中独立主题分组、手输快捷键、首次启动主动添加模型以及先打开迁移进度页的描述。

快捷键输入改为直接捕获键盘事件；记录完整组合后停录并聚焦保存，可再次点击录制框或「重新录制」按钮替换，或显式追加连续组合。单独修饰键、IME 组合输入、粘贴文字不能提交。录制消费按键，不执行原命令；浏览器/操作系统截获的组合不得假装可录制。每命令仍有多绑定、平台独立，保存前校验系统保留、同命令重复和跨命令作用域冲突。跨命令冲突使用独立对话框列明命令及绑定，提供取消、删除冲突命令的冲突绑定再保存、跳转该命令查看；多个命令冲突时逐项显示并提供对应查看入口。转移只删除冲突绑定，不删除命令或其其他绑定；确认后原子保存，失败所有已确认集合不变且草稿可重试。跳转不保存草稿，定位并聚焦目标命令。系统保留组合不可转移。

设置窗口外有柔和投影；鼠标点击窗口和其子对话框以外区域立即关闭整套设置，保留已确认配置和创作草稿，丢弃未保存的用户/模型/快捷键草稿并取消模拟测试、失效迟到回调。不对外部点击增加确认，不把同一次点击穿透为工作台操作。子对话框内部操作不关闭设置；迁移执行阶段不属于设置外点关闭规则，继续遵守路径提交前可取消、提交后完成清理再关闭的安全约束。调试工具栏不是产品窗口，操作它不模拟外点关闭。

首次启动中央去掉「添加你的模型」，允许离线创建和手动创作。任何 AI 执行入口均在调用前检查所需类别、已保存授权和选择；从未配置对应类别时弹出「尚未配置模型」并引导配置；已有但停用/无 Key/未选择时准确说明不可用原因，不能伪称没有配置。文本、审核、文生图均受同一门控规则约束；跳转对应类别，保留任务输入和作品目录，配置后不自动重放任务，须作者主动再次执行，不回退平台模型。纯浏览模型列表不弹缺失提示。原型只演示代表性执行入口，最终所有生成/审核/摘要/重试/图片等路径必须纳入真实 App 测试。

通用「迁移」先打开系统目录选择器，取消不改变路径、不开进度；选择并确认有效目标后才启动迁移并展示过程/结果。目录相同或不合法时不启动，权限/空间/身份校验失败保留旧根。选择器确认文案说明选择后开始迁移，避免意外启动。默认作品父目录的「选择」同样调用系统目录选择器，确认后更新，取消保持。设计稿只能展示系统选择器位置与样式示意，不冒充真实文件系统选择；实际 App 使用原生目录选择器、仅目录模式。

系统菜单「玄印 / 关于玄印写作」在 macOS 打开原生统一样式 About 面板；Windows 帮助菜单打开独立「关于玄印写作」窗口。它们不导航到设置的关于我们页，显示应用标志/名称和实际安装版本，关闭返回原工作台。设置中的关于我们保留反馈及尚未上线的文档入口。当前 App 未发布，不能把 UI 稿版本充作安装版本。原生父子窗口、焦点、版本来源和两平台外观最终在 Electron 验收。

更详细的冲突与原生系统边界见 `desktop-menu-shortcut-contract.md` v0.4。以上仍属 UI 审核阶段，不提前开始技术方案或 App 实现。
