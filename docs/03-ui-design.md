## 1. 审核材料与边界

交互稿：`design/desktop-preview.html`。默认在顶部显示调试工具栏：平台、色板、页面、异常状态。工具栏在 App 外独占一行，可换行，不覆盖原生窗控或设置；不属于安装版 UI。Alt+Shift+P 切换显示，`?review=0` 提供无工具的纯 App 预览，刷新默认重新显示。切调试页面关闭/取消子配置及其测试，平台/色板切换保持模型/资料草稿；切平台取消快捷键录制及恢复确认，保留已确认绑定。示例作品/模型/路径/测试结果均为演示数据。设置只在内存，刷新会重置；头像仅在用户显式选文件后读取预览，不写盘。不保存 Key，不连接模型，CSP 禁止 fetch。反馈按钮为明确的用户外部导航。

当前仅为 UI 阶段。没有 Electron 窗口、原生按钮、磁盘事务、真实模型调用或安装版本，不能将原型检查作为 App 验收。原型的窗控是位置示意，最终使用系统按钮；关于页标注尚未发布，最终从实际安装包读取版本。

最终 App 复用原 React 工作台及 29 类面板，产品能力矩阵仍完整约束实现。原型只演示桌面差异。

## 2. 与 Web 保持一致

保留侧栏作品树/会话树、对话流/引用 chip/候选与批准入口、内容 Tab、MarkdownEditor 预览/编辑/分屏、版本与评论、草稿和编辑实例。新设置关闭不重挂载编辑器。语义令牌直接来自原 `globals.css`；标志复用温玉 SVG，Lucide 和中文字体均本地提供，来源见 `assets-provenance.json`。阅读面保留纸纹，玄墨界面保留墨石纹理。

允许桌面差异：顶部栏内系统按钮/视图导航、侧栏本地用户资料、作品路径授权、离线创建、用户设置、迁移/恢复。只有 paper / ink 两套色板，跟随系统是主题选择规则。

## 3. 无边框工作台

取消独立顶部标题栏和底部全局状态栏。左导航、中对话、右内容填满窗口，垂直分隔线从顶部贯穿到底部。首启保持原两栏，内容展开后为三栏；常规侧栏初值 260px，沿原布局逻辑分配余下空间。

左导航顶部 47px 栏内，macOS 系统交通灯、后退、前进、侧栏展开/收起依次排列。截图参考用于位置与风格，顺序按用户文字要求。按钮组下方保留原品牌与创作入口。侧栏收起时，当前面板头部提供相同导航工具；窄窗侧栏浮层从 y=0 起，不留标题带。

Windows 窗控在右上角当前可见面板头部，预留约 138px 安全区，不遮住 Tab/内容切换。顶部各栏的空白可鼠标拖动；按钮、输入、菜单、系统控件不拖动。Mac 最后窗口关闭/Dock重开、全屏、Windows 吸附、DPI、失焦状态必须在真实桌面验证。

后退/前进在窗口内视图历史移动，边界禁用，不操作网页浏览历史。原型仅演示正文/新对话之间的历史按钮状态，最终按原工作台视图完整接入并保留草稿。

## 4. 设置容器

最大约 960 × 730px，空间不足时填可用区域，右内容独立滚动。分类宽 172px，窄窗 126px；分类顺序固定：通用、用户、智能体、模型、外观、快捷键、关于我们。设置采用纯左右结构，标题位于左导航顶部，关闭位于右内容右上角；右侧不重复分类大标题，也没有顶部标题栏或底部保存/取消。

除用户编辑和模型配置外，合法设置修改即时响应，收到原子本地回执后显示已更新。输入无效保留待修正内容，上一有效配置继续使用；持久化失败显示原因、保留待处理修改和重试入口。切组、关闭不回滚已确认配置，也不出现未保存确认框。原型只演示这些状态，不承诺真实持久化。

主对话框与配置子对话框分层：最高层获得焦点，下层 inert，Tab/Shift+Tab 循环，Escape 关闭最高层；清除/删除/停用与目录迁移仍是独立明确操作；测试直接启动，结束结果弹层保留原配置草稿。设置打开后作品草稿保持。

### 模型配置对话框

宽约 620px，主体可滚动，底部固定右对齐「保存模型」「测试连接」「取消」。无重试更新、默认用途或模型分类。类别继承文本/文生图列表入口；编辑保持原类别。

供应商使用原 Web 组件体系的可访问下拉选择样式，每项左侧对应彩色 Logo。顺序为 OpenAI、Anthropic、Google、xAI、深度求索、月之暗面、智谱、Xiaomi、阿里巴巴、MiniMax、腾讯、字节跳动、自定义供应商。智谱使用 z.ai 官方黑底圆角块、白色Z图形；与当前 Web 引用同源，保留官方可见路径/配色，去掉无用 Illustrator 样式。供应商菜单按匹配类别的输出模型目录过滤；文生图当前显示 OpenAI、Google、xAI、智谱、阿里巴巴、MiniMax、腾讯、字节跳动，文本显示上述全部十二家；两类均保留自定义。该范围是本次官方依据的快照，不是永久白名单，安装版依据已核验的能力元数据更新，未知能力不猜测，提供发现失败/重试提示。已保存记录不因目录刷新被删除，失效记录可编辑。自定义为通用图标。菜单可滚动，方向键/Home/End 导航，Enter 选择，Escape 先关菜单并返焦触发器，外部点击关闭。来源/处理方法见 `design/provider-logo-provenance.json`。

非自定义下方仅 API Key 与供应商模型列表。预设协议/地址/高级参数隐藏，不显示默认用途/分类。自定义显示供应商名称、协议、展示名、Base URL、模型 ID、Key；可选上限在折叠高级区。主协议只有 OpenAI / Anthropic。预设端点/区域依据见 `provider-ui-presets.md`。

正式 App 加载完整匹配类别目录与 Key 可用状态，处理全部分页与加载/认证失败/权限未知/重试；不拿精选项或第一页冒充完整目录。当前原型明确显示「设计示例」和示例计数，demo ID 不可用于真实调用，夹具不能证明真实模型或思考/图像能力。供应商发现的剩余核验见 `provider-catalog-research.md`，不在 UI 阶段假称实现完成。

添加和编辑均用 radio 单选，每次配置一个模型；两者没有模型行高亮背景，已添加项禁用且标注，防重复。已保存两组列表也去掉选中背景/当前标签；会话模型选择仍沿原 Web 控件。

草稿与已确认列表隔离，保存校验后一次提交，失败保持草稿/旧记录。取消/X/Escape 只丢弃草稿并返焦原入口。Key 不回填明文；同范围留空保留原 Key。改草稿供应商/协议/地址清空草稿 Key 和旧能力元数据，自定义未核验能力仅提供模型默认，成功保存授权范围变更或更换 Key（含同供应商/端点）才撤销旧授权、增加授权版本并取消旧请求；取消不会损坏已确认模型。

测试连接不打开前置对话框，直接在当前配置框中逐项测试全部已选模型。配置框显示已选数量、每个文本模型请求简短回复/每个文生图模型生成1张图片与可能费用；原型仅模拟不联网。按钮显示旋转图标、「测试中 i/n」与 aria-busy，禁用至整批结束；字段/供应商/型号及保存暂时禁用，取消/X/Escape 可关闭配置并取消本批次。快照固定供应商、端点、Key 与型号，测试期间不更换目标。完成后结果弹层覆盖原配置，逐型号显示供应商、端点与成功/错误（不显示 Key），结果层获得焦点，原配置 inert。结果的返回/X/Escape 只关结果，恢复同一未保存草稿并返焦测试按钮；Tab/Shift+Tab 仅在最高层循环。测试不修改模型列表、会话选择或智能体默认值；关闭配置隔离异步回调，重开不得收到旧批次结果。显式停用/删除确认后立即撤销调用授权、保留候选/草稿，关闭设置不恢复。

### 智能体

放在左侧「模型」上方，图标沿用机器人；「模型」图标改为 Lucide box 立方体。右侧从上至下是默认模型、默认模式、默认思考强度、默认审核模型、默认文生图模型。模型选项只取已保存、已启用、Key有效且能力匹配的记录，不取配置草稿；文本与文生图严格隔离，无候选时引导先添加。失效引用显示原模型不可用，删除清空，不自动替代。

默认模式只有标准模式/计划模式。思考选项随默认文本模型实际能力变化，不支持时禁用并解释；换模型后不兼容档位重置为模型默认。此页即时更新，无保存/取消；失败显示保留待处理修改，重试重新核验引用。新默认应用于新会话/任务，不改当前会话或在途请求。原型示例档位不是能力事实；正式实现复用原 Web 思考解析与会话模式组件。

## 6. 目录、迁移与恢复

沿用已审 v0.3 流程：每次新建必须重新取得作品目录授权；建议目录不等于确认。非空冲突、已绑定目录、只读等具体错误紧邻字段；未选择时创建禁用。放入对话草稿仅挂起授权/模板，不发送模型；手动创建打开空概览，模板仍在输入草稿。取消清除挂起授权，新对话隔离，第二作品不得复用已绑定目录。

迁移显示源、当前权威根、显式目标与清理范围。提交前可取消，提交后所有关闭/切换路径守卫，Windows 路径同步更新；快照在新根，作品与未知文件不清理，旧副本待清理不能算完整成功。根失联不悄悄退回旧根；快照校验后选恢复目录，损坏备份不可恢复。草稿恢复先比较，进入可编辑且未提交的恢复稿。关闭前保存失败提供重试、导出、取消关闭，X/Escape 按取消关闭处理。

子代理检查产品一致性、字段/密钥边界、实时反馈、窄窗可达性、分层焦点、旧目录/恢复保护及证据真实性。**用户明确批准此 UI 稿后才进入技术方案、测试用例和 TDD App 实现。** 当前请求是修订设计，不构成批准。

## 8. Web UI 复用边界与来源

桌面专属差异之外，最终 App 完全沿用当前 Web UI，不另做桌面创作界面。下列是实际实现的来源绑定，不是设计灵感；迁移需保留组件和其交互，不用此静态稿替代 React 原件。

| UI 范围 | Web 原来源 | 桌面允许差异 |
| --- | --- | --- |
| 分栏/布局/内容容器 | `src/components/layout/DashboardShell.tsx` | 去掉独立顶栏/全局状态栏，窗控/视图历史与拖动安全区 |
| 树与底部账号菜单 | `src/components/layout/SidebarTree.tsx`（账号菜单 2089–2169） | 本地资料；原向上菜单保留头像、笔名/邮件、外观切换，加入设置、去除旁侧齿轮；移除平台登录/退出与管理员链接 |
| 菜单容器/键盘 | `src/components/ui/dropdown-menu.tsx` | 最终复用原 DropdownMenu，原型仅演示结构与 Escape/外部点击/方向键 |
| 对话、引用、候选与任务 | `src/components/layout/ChatPanel.tsx` 及原子组件 | 作者模型来源与目录授权；其他布局/组件不变 |
| 正文编辑/预览/分屏 | `src/components/editor/MarkdownEditor.tsx` | 本地服务接入；保留编辑实例、自动保存、评论锚点、候选批准 |
| 全部其余创作面板、按钮、Tab、向导 | `source-inventory.json` 与能力矩阵列出的原组件 | 只加明确授权的作品目录与离线手动创建；其余不重设计 |
| 主题/标志/图标 | 原 `src/app/globals.css`、温玉 SVG、Lucide | 两色板不变；设置中的主题示意图是用户指定的桌面专属改动 |

底部用户触发器沿用 Web 24px 头像、12.5px 姓名、10.5px 等宽邮件、7px 圆角；弹出菜单向上左对齐，标签为 32px 头像、姓名与邮件，下方为原外观行（宣纸/开关/玄墨）与新增设置。菜单切换主题是显式选择 paper/ink，覆盖此前系统跟随；系统跟随仍可在外观设置选择。菜单关闭还原触发器焦点。

编辑用户没有「修改自动更新」或「重试更新」。头像列与右侧属性列在表单区域等高；点击头像打开系统文件选择。图片只在草稿预览，保存时与属性一次提交。所有取消路径及重新打开都会取消读取/隔离异步会话；失败再次点击保存，成功返回用户卡片。模型配置按本次第5节手动保存；其他即时设置与显式模型撤销遵守各自提交边界。


停用是可逆管理操作：列表提供显式「启用」入口，核验已有 Key 与字段后恢复该记录可用性；不自动改选其他模型，也不启动请求。先前对同一模型的默认引用可恢复有效，思考使用模型默认；删除不恢复引用。启用写入失败保持停用。


### v0.8 模型图标与选择器

所有模型项左侧显示模型家族Logo，不把供应商主体Logo误作其所有子品牌。已核验示例映射：Claude、Gemini、Grok、Kimi、Qwen、混元、豆包使用各自图形；GPT、DeepSeek、GLM、MiMo、MiniMax对应已有品牌图形；GLM使用本轮黑底Z.ai。自定义/未知用通用图标；正式应用按真实模型家族元数据与原 ProviderLogo契约映射，不按作者输入名称猜测。来源分别见 `model-logo-provenance.json` 与供应商来源文件，所有资源本地。

智能体的默认模型/默认审核模型/默认文生图模型改为能显示图标的可访问下拉：触发器显示当前Logo与名称，选项为Logo、名称、供应商/ID，空值与失效值明示，不自动补位。沿原组件体系的语义令牌、圆角、浮层与滚动；方向键/Home/End/Enter/Space、Escape返回触发器、Tab关闭及外部点击均可用，文本与图像记录过滤及即时失败重试不变。

对话选择器沿 Web ModelPicker 的紧凑图标触发器、向上菜单与模型项图标/当前勾选；只列当前有效文本记录，管理模型入口和空态可达，切换模型保留输入草稿/正文实例、不改智能体默认或自动请求。完整思考子菜单和任务路由最终直接复用原 React组件，当前原型只演示模型切换；其他 Web 位置（问答/任务导航等）最终共用原 ModelPicker，没有另建界面。

配置目录型号与已添加模型列表也显示家族Logo；没有增加模型行选择高亮或供应商额外字段。主题示意图的标题/正文为纯图形占位，文字可见性与主题名称放在图示之外。

## 9. v0.9 操作系统菜单、下拉目录与编辑设置

产品补充见 desktop-menu-shortcut-contract.md。macOS 在调试行下方显示系统桌面菜单位置示意（玄印/文件/编辑/视图/窗口/帮助），不占 App 的三栏头部；Windows 仅在右上窗控左侧有菜单图标，展开五组与二级项，窗控安全区同步扩展。平台切换/窗口缩放/工具显隐关闭菜单并保持可见焦点；模态配置期间禁用应用菜单入口，防止应用动作打断配置。帮助文档未上线时菜单项也禁用，反馈仍为用户主动外部导航。

预设可用模型为搜索滚动下拉，添加和编辑均只选一个模型；收起显示名称和 Logo。供应商/目录/智能体/会话模型仍有 Logo；GPT 家族黑白标，Kimi 黑色圆角块白 K（来源清单记录官方字形和用户指定底板），月之暗面供应商图形不与家族混同。自定义去输出输入，上下文输入支持整数/K/M十进制单位；保存规范化。下拉不足空间向上，滚动窗口时关闭；busy 关闭并锁定、完成恢复；测试结果返回保持同一草稿。

外观「界面」含字体/字号/缩放，「正文」含字体/字号/行距/行号/自动换行。默认不换行；行号仅源码，阅读保留原版书页排版。原型用 textarea/gutter 演示，软换行按实际字号/宽度测量每逻辑行高度并随尺寸重算，实时修改外观不重建编辑实例，输入值和选区保持；最终仍复用 MarkdownEditor / Monaco 及评论、撤销、自动保存契约。支持本地字体回退。

快捷键来自 desktop-commands.js（131个稳定ID，按平台过滤），所有菜单共享该来源；四类搜索/过滤、默认与当前值、作用域、保留项、未绑定项均展示。两平台自定义绑定独立；切平台取消录制/恢复确认，模型草稿保留。配置支持清除/冲突校验、失败保留、恢复默认确认；原型文本模拟录制，不实际注册系统热键/执行完整编辑命令。最终 Monaco 全部可用动作从运行时动作/keybinding注册补齐，不能把静态目录条数冒充真实编辑器完整动作数。

本版证据仅覆盖此修订；历史版本计数不累计。真实 Electron 系统菜单、窗口动作、完整 Monaco/输入法/原生快捷键和两平台安装包仍待实现及最终用例。用户批准 UI 后再进入技术方案。


## 10. v0.10 逐行设置、单模型与多快捷键

本节覆盖旧版中的添加多选和单快捷键表述。交互契约以 `desktop-menu-shortcut-contract.md` v0.2 为准，产品 v0.9 已通过独立复审。

- 设置采用圆角分组、细分隔线，一条配置占一行；名称与说明在左，控件在右。通用路径、备份/导入导出、智能体默认项、主题/界面/正文配置均遵循同一布局。主题仍在同一行提供三张图示；模型列表、资料卡、关于条目保持各自一行。用户编辑保留左侧头像占满表单高度，右侧笔名和邮件各一行；模型子对话框也以逐行配置展示。窄窗保持左右关系，说明可换行、长路径省略、模型名在菜单内换行，内容区滚动。
- 预设模型的添加与编辑都只能选择一个。搜索、长列表与类别过滤保留；选中后收起并返焦触发器，触发器显示该模型名称/Logo。方向键只移动焦点，Enter/Space 选择；当前选择不因搜索消失而丢失。已添加项禁用，保存/测试只作用于这一模型，取消不创建记录。
- 每个命令占一行，右侧展示绑定集合。每个键帽可点击编辑，旁边 X 只删除该绑定，行末 + 添加一个。多个键帽在该命令行内换行；空集合显示「未设置」。系统保留命令不可添加、编辑或删除。搜索匹配任一绑定、默认值、名称与 ID。
- 添加/编辑使用独立确认框；取消或失败保留已确认集合，失败保留录制草稿。删除即时生效，失败保留原项。只删除最后一项时仍保持显式空集合，不恢复默认。所有绑定参加相等/前缀、别名、作用域和保留键冲突校验；编辑时只跳过当前项。
- 菜单显示第一个绑定；编辑/删除第一项即时同步，空集合不显示键帽。macOS/Windows 独立，切平台取消录制/恢复确认；恢复默认需确认且只恢复当前平台。操作后焦点返回当前/相邻键帽或添加入口，过滤后命令消失则返回搜索框。

本版仍为内存交互稿。快捷键录制为文本模拟，真实键盘事件/Monaco动作注册、本地持久化和 Electron 菜单将在 UI 获用户批准后实现与验收。
