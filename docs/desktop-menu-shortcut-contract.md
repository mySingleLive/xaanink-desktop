## 菜单位置和命令

macOS 在系统桌面顶部原生菜单栏提供「玄印、文件、编辑、视图、窗口、帮助」。玄印为用户指定的菜单名，其余品牌仍为玄印写作。设置、关于、隐藏/显示、服务、退出放玄印菜单；文件承载作品创建/打开、对话创建、保存/导出、关闭标签；编辑提供撤销/重做、剪切/复制/粘贴/纯文本粘贴、全选、查找/替换；视图提供三种正文模式、面板显隐、缩放、行号/换行；窗口提供最小化、最大化/全屏、关闭；帮助提供文档和反馈。系统保留角色与操作不可被任意重绑定。

Windows 保持无标题栏，在右上角最小化/最大化/关闭组的左侧加入菜单图标。展开五项「文件、编辑、视图、窗口、帮助」，各项打开二级菜单；设置/退出在文件、关于在帮助。按钮属于非拖动区域；窗控与菜单共用安全区，不压住内容标签。菜单在正常三栏、侧栏收起、内容区隐藏/全屏及窄窗均可达。Escape 逐层返回，方向键/Enter 导航，外部点击退出；平台切换关闭旧菜单。

原生呈现参考 [Electron Menu](https://www.electronjs.org/docs/latest/api/menu)：macOS application menu 与 Windows window menu 的位置不同；最终接入原生菜单/角色及自定义入口，原型中的 macOS 桌面条仅用于审核示意，不是在 App 内添加标题栏。浏览器不能证明原生菜单或系统窗控已实现。

菜单和快捷键使用同一稳定命令 ID、标签、可用条件和绑定来源。菜单显示当前已确认快捷键，改绑定后同步，不能存在两套映射。编辑命令作用于菜单打开前聚焦的编辑实例/输入框，不能因菜单抢焦把正文操作路由到其他输入。只读预览不允许剪切/粘贴修改；复用 Web 的 MarkdownEditorHandle / use-editor-commands 和 Monaco 撤销栈、版本/自动保存契约。应用菜单不绕过用户批准候选稿边界。

## 可用模型下拉与参数

预设供应商仅显示 API Key 和「可用模型」下拉列表框。新增与编辑都只允许选择一个模型；选择另一项替换当前草稿中的型号，收起显示模型名称和 Logo，展开显示搜索、家族 Logo、模型名/ID、已添加禁选及无结果状态。列表有固定最大高度并滚动，窗口不足时向上展开/限制高度。切供应商清除该草稿 Key 和型号，不保存；测试开始关闭列表并锁定入口/搜索/选项，结束才恢复。目录再多也不拉长主配置框。完整真实目录由最终供应商能力目录提供，示例不冒充全量。

GPT 家族使用黑白 OpenAI 标，宣纸黑色/玄墨白色；月之暗面供应商与 Kimi 模型家族区分，Kimi 使用黑色圆角块、白色 K 图形。用户指定的 Z.ai 图形继续保留。图标资源记录来源和指纹，不执行外部包代码。

自定义配置去掉「输出上限」输入。上下文上限可为空，或使用正整数 / K / M 表示 token 数（128K = 128000，1M = 1000000，十进制）；不接受零、负数、未知单位和小数 token。保存时规范化整数，显示时可保留友好单位。该值是作者提供的能力提示，不能据此自动确认供应商能力。隐藏输出参数仍按协议/模型元数据产生合法默认值，Anthropic 等必要字段不因删输入而漏发，也不要求用户通过隐藏字段修复校验。

## 外观

保留三主题与纯图形主题缩略图。在外观页把「界面与正文」拆为两块：界面含界面字体、界面字号、缩放；正文含正文字体、字号、行距、显示正文行号、正文自动换行。字体选择系统默认/可用本地字体，不联网下载；不可用时回退并提示实际字体。正文字体/字号/行距适用于阅读及编辑，行号只在编辑/分屏左侧源码区显示；预览永远无行号。自动换行默认关闭，只控制编辑/分屏源码，阅读预览保持 Web 书页排版。无需关闭/重开编辑器；修改不能丢失未保存内容、选区、评论锚点或撤销栈。失败继续使用已确认配置，保留待处理值和重试。

## 快捷键覆盖与作用域

搜索框、右侧恢复默认、下方列表保留，新增按类别过滤和作用域/默认值显示：应用菜单、Markdown 编辑器、AI 输入框、普通文本输入框。所有菜单动作（包括未绑定动作和原生保留动作）均有条目；多个菜单引用同一动作只占一个 ID。Markdown 包括文字格式、标题1–6、链接/图片、引用/列表/代码/表格、查找替换、定位/选择/多光标、缩进/行操作、评论和编辑器视图，以及当前装配 Monaco 的全部可用动作；AI 输入包括发送/换行/停止、引用候选导航/确认/关闭、模型选择与会话搜索；普通输入包含剪贴板、撤销重做、光标/词/行首尾/全文选择、删除和确认/取消。

最终 App 从当前 Monaco 实例的动作与 keybinding 注册信息补齐全部受支持动作，不靠手写清单截断默认能力；命令名、内部 ID、作用域、当前键和默认键都可搜索。静态原型列出桌面命令及相关代表性编辑动作，不能据其条数宣称已经枚举/执行了真实 Monaco 全部动作。

冲突按作用域和同时激活条件判断：全局与任何局部冲突；同类输入冲突；互斥的 Markdown 与 AI/普通输入可复用组合。相同共享编辑 ID 为一个命令，菜单与输入场景复用它的绑定集合。支持 chord 组合，区分平台，macOS 绑定不因切 Windows 被改成另一组合。IME 组合期间不触发发送/菜单/热键，菜单或对话框已消费的 Escape 不再触发停止任务。录制过程中组合不执行原命令。系统保留键显示但禁止覆盖；普通功能未绑定仍可通过菜单或命令入口操作。恢复默认覆盖当前平台全部自定义绑定，需要明确确认，取消保持原值。

## 设置逐行布局与多快捷键（v0.2 新增，布局以 v0.3 补充为准）

设置各页采用系统设置式分组行：每行只放一条配置，左侧名称/简短说明，右侧控件或动作，分组面板使用原宣纸/玄墨语义令牌、细分割线与圆角。取消并排的两项表单；主题作为一个配置行，右侧仍有三张图形缩略选项。目录显示完整路径提示并保留选择/迁移动作；备份、配置导入/导出各占一行。用户卡片、模型清单、关于信息也按横向行呈现。独立模型配置采用相同字段行；用户编辑保留此前明确要求的左头像/右属性布局，右侧笔名和邮件各占一行。窄窗仍保持标签在左、控件在右；说明可折行，长值截断可查看完整值，选项/菜单独立滚动。

可用模型新增和编辑均单选，不显示复选框或多选数量。搜索过滤不得清掉已选模型；选择后收起下拉并返回触发器。方向键只移动候选焦点，Enter/Space 明确选择；已添加条目仍禁选；一次保存只提交一个记录、一次测试只针对一个草稿目标。测试锁定、迟到结果隔离、取消/手动保存与 API Key 授权边界保持。

每个命令拥有当前平台的有序绑定列表。默认组合保留为第一项；「添加快捷键」追加，不替换原绑定。每个键帽分别可编辑/删除；编辑只改这一项，删除只移除此项，删至空显示「未设置」且保留添加入口，不能回落为默认绑定。新增/编辑在独立弹框保存后生效，取消保持全部旧绑定；删除即刻生效。失败不修改已确认集合，新增/编辑保留输入，删除失败保留该项并允许重试。系统保留命令所有绑定只读。

校验遍历所有命令的所有绑定，包括同命令的其余绑定；只跳过正在编辑的那一项。相等、规范化别名重复和连续组合前缀冲突按既有作用域规则拒绝，互斥输入域仍可复用；每段系统保留组合都拒绝。搜索匹配任意一个当前绑定，另保留默认组合/命令/ID/作用域搜索。菜单显示第一项为主快捷键，后续绑定也有效；编辑/删除第一项后菜单同步，删除到空不显示键帽。列表顺序即主键优先级，本轮不新增重排交互。最终 Electron 需为剩余绑定注册同一命令，静态原型不执行系统热键。

每个平台保存独立完整集合；切平台取消新增/编辑及恢复默认弹框，保留模型/用户草稿。恢复默认仍确认后仅重置当前平台整套绑定，不能修改另一平台。编辑/删除后焦点返回该命令的相邻绑定/添加按钮；若搜索导致行消失，返回搜索框。

## 长字段与卡片布局（v0.3）

本节覆盖 v0.2 中所有配置都左右排列的限制：仍是一条配置独占一行，但目录/文件地址等长文本路径采用标题在上、输入区域在下的结构；输入区域占满配置行可用宽度，选择/迁移按钮与路径组件同行。长路径仍可查看完整 title，不修改路径选择、授权或迁移行为。

外观的主题也采用上标题、下方整行三个主题图示的结构。宣纸/玄墨/跟随系统保持同排单选和即时生效。界面/正文的短选项和开关、智能体设置仍保留左右排列。

「配置模型」的所有属性（含供应商、API Key、可用模型、自定义名称/协议/地址/ID与高级上下文）都采用上标题、下控件，输入与下拉占满表单可用宽度，说明在控件下方；每项仍独立，不并排多个属性。较长表单由内容区滚动，底部保存模型/测试连接/取消保持可达。下拉沿用搜索、边界定位、单选与焦点/草稿保护。

模型清单卡片适当增高，增加垂直内边距，维持文本/文生图分类、名称/ID/Logo/状态和行内操作。用户卡片改用两主题语义颜色组成的柔和背景，与设置内容面区分；头像/笔名/邮件和编辑入口保留。编辑改为纯铅笔图标按钮，仍有「编辑用户」可访问名称和悬浮提示，键盘可达；不额外显示编辑文字。长笔名/邮件不得挤出编辑按钮。用户编辑对话框继续保留左侧全高头像、右侧属性和保存/取消，保存前不提交。

本次只改变上述桌面专属设置布局，不改变快捷键多绑定、模型单选/测试/保存、用户手动保存或其他 Web 工作台设计。

## 本阶段验证边界

本轮只验证原型菜单层级、显示/搜索/绑定/冲突、模型滚动选择和草稿隔离、字体/行号/换行表现、窄窗/主题/平台回归。原型不注册系统热键、不操作真实剪贴板或生成接口、不执行原生退出/磁盘保存，不伪造完整 Monaco 或 Electron 验收。原生菜单、菜单打开前焦点、编辑命令、键盘布局/IME/辅助功能及两平台安装包均须进入最终测试用例并在真实 App 验证。

## 桌面交互补充（v0.4）

本节及产品第17节覆盖此前独立主题组、手输录制、跨命令冲突一律拒绝的旧描述。主题是「界面」首行；其上下结构及短配置左右结构保持。

录制框只读且可聚焦，显示当前完整按键组合。完成一次记录后焦点到保存按钮，允许录制 Tab / Escape 本身，又能继续用 Tab 导航；点击录制框或「重新录制」按钮重新录制，追加连续组合按钮明确进入下一段。修饰键预览不构成可保存绑定；释放后恢复上次完整草稿。忽略重复键、Dead / Unidentified 和 IME 组合事件；不接受粘贴文本。采用平台名称并规范化组合；默认 Plus 与常见键盘 Shift+Equal 视为相同，小键盘 NumpadAdd 保持独立；真实键盘布局、非美式键位、IME 与系统拦截必须在最终原生 App 验收。

跨命令冲突包括相等和 chord 前缀，按原作用域规则判断；冲突对话框覆盖录制框但保留其草稿。取消回录制；删除并保存再次校验后一次提交所有受影响集合；多个冲突逐条列明，不可只处理首个。同命令重复与系统保留继续在录制框内拒绝，无删除系统绑定按钮。跳转清除当前未保存录制，展开全部分类并用稳定命令 ID 定位目标；操作后焦点可见。失败或切平台不允许半次转移。

外点关闭适用于设置及其未提交子草稿，迁移过程另有提交边界。关闭使文件预览读取、模型测试、录制和目录选择上下文失效；已确认设置与创作输入不回滚。同次点击不得穿透。窗口投影在两主题/窄窗可见且不遮内容。

目录确认即授权本次迁移，迁移不是打开设置就执行；通用页持续显示当前根、预计数据大小、作品不移动及旧根清理范围，选择器确认前再次明示。此流程替代旧版进度页再确认执行的步骤。原生参照 [Electron dialog.showOpenDialog](https://www.electronjs.org/docs/latest/api/dialog)：使用目录模式，返回取消或所选目录；浏览器不能证明系统选择器、目录写权限或真实迁移通过。macOS 关于窗口参照 [Electron app.showAboutPanel / setAboutPanelOptions](https://github.com/electron/electron/blob/main/docs/api/app.md)，Windows 使用独立关于窗口；实际版本由安装包提供。UI 原型只展示位置/样式与关闭返回关系。

AI 执行门控按任务所需文本/审核/图像类别检查记录、启用状态、Key 和已选择模型。空配置只是其中一类失败，不能把所有失败都叫未配置；引导保留输入，配置后不自动执行。调试工具可提供三类门控的示例入口，但不加入安装版或改造 Web 工作台。
